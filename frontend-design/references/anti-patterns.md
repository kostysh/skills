# Anti-Patterns

Use this reference when the output feels generic, overdesigned, or mismatched to the brief.

## AI-slop defaults to reject

- generic purple or blue gradients with no brand reason
- interchangeable SaaS card mosaics
- safe default font stacks that flatten the tone
- arbitrary glassmorphism or glow effects with no hierarchy benefit
- filler icons, badges, pills, and stat chips
- too many parallel accent colors
- decorative shadows trying to replace composition

## Landing page failures

- image exists, but the brand is still weak
- hero copy is long enough to become a document
- multiple competing visual anchors in the first screen
- support sections repeat the same claim in different wording
- dashboard mockups floating in space with no narrative role

## Product UI failures

- every panel wrapped in a card by habit
- marketing copy on operational surfaces
- decorative backgrounds behind routine tables, filters, or forms
- low-information chrome crowding out the actual work surface
- visual density with no grouping logic

## Motion failures

- motion appears everywhere but changes nothing
- transitions are too slow for product work
- scroll effects reduce readability
- hover effects exist only as decoration

## Recovery moves

- remove one third of the copy
- remove half of the decorative wrappers
- reduce the accent system to one dominant accent
- re-establish one dominant idea for the first viewport
- replace generic components with stronger composition
- check whether the design still works with most shadows removed

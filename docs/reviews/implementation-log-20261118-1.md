Команда `verify:package` на установленном npm 12.0.1 первоначально остановилась при чтении сведений о пакете. npm 11.18.0 выдаёт для `npm pack --json` массив, а 12.0.1 — объект с ключом имени пакета. Проверка теперь принимает обе фактически полученные формы. На обеих версиях прошли установка локального архива CLI, вызовы через npx и pnpx/dlx, install/update и проверка ошибки. [Изменение формата в npm](https://github.com/npm/cli/pull/9747)


Полная компиляция некоторых авторских пакетов переносит указатель `docs/README.md` отдельно от журнала этой кампании. В навигации 01, 03, 06, 07 и 08 сохранена ссылка на локальный журнал и добавлена ссылка на ту же зафиксированную Git-версию для получателя автономной сборки. В проверенной компиляции совпали байты всех 4, 3, 6, 3 и 24 файлов соответствующих поставок.

## D-001 — Wording for an unknown save error

The [decision register](decisions.md#d-001--wording-for-an-unknown-save-error) records “Save failed” under the owner's approved class for reversible generic internal error wording. It tells the user the save failed and contains no personal data. Reversal requires a copy edit and a register update.

Recommend confirming D-001. Confirmation settles the wording for any later implementation of the fallback. A revised choice would require updating the register and using the replacement in that work.

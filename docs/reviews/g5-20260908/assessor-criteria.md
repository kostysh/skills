Для каждого запуска сохранить исходный вход, выход и доступные tool events, снимок, назначенную модель/settings, наблюдаемую metadata и экспозицию. Trial verdict: PASS / FAIL / INCONCLUSIVE. Отдельно учитывать реальную границу интеграций: синтетические данные не доказывают email/GitHub/runtime. Повторять или варьировать случаи только по гипотезе о конкретном сбое. Сравнение baseline/candidate использует одинаковые входы и критерии; новые риски требуют явно версионированного дополнения, а не подгонки старых критериев.

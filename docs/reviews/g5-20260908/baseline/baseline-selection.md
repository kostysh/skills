| Запрос | Основной навык | Обоснование |
| --- | --- | --- |
| S1 | `prd-engineer` | Каталог прямо относит создание PRD и требований новой функции к этому навыку. |
| S2 | `requirements-approval` | Навык обрабатывает ответы заказчика в процессе согласования требований и передаёт принятые решения в авторитетные документы и GitHub. |
| S3 | `code-reviewer` | Навык предназначен для проверки diff на ошибки и регрессии без внесения изменений. |
| S4 | `retrospective-analysis` | Для разбора причин одного завершённого сбоя каталог предусматривает целевой режим ретроспективы одного инцидента. |
| S5 | `skill-reviewer` | Проверка качества инструкций AI-agent skill прямо входит в область этого навыка. |
| S6 | `spec-conformance-reviewer` | Навык сопоставляет реализацию с авторитетной спецификацией и выявляет несоответствия. |
| S7 | `architecture-engineer` | Проектирование архитектурных границ и обоснование ADR прямо перечислены в назначении навыка. |

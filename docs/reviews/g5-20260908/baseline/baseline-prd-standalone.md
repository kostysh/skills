**Черновик PRD: экспорт списка задач в CSV**

Статус: не утверждён (`Authority: non-authoritative`). `Handoff: draft-only` — без передачи в разработку. Владелец: владелец внутреннего инструмента. Единственный источник требований — ваше сообщение.

**Проблема и результат.** Сотрудники команды сейчас копируют строки вручную. Сотрудник должен получать CSV текущего отфильтрованного списка задач, сохраняя состав и порядок отображаемых данных.

**Требования:**

- Сотрудник запускает экспорт из текущего списка и получает CSV.
- Экспорт содержит только видимые строки и столбцы, в текущем порядке.
- Экспорт сохраняет значения отображаемых данных.
- Содержимое фильтров сохраняется. Допущение черновика: экспорт не меняет заданные фильтры; включение описания фильтров в CSV не подразумевается.

**Критерии приёмки:**

- Сотрудник применяет фильтр, меняет порядок строк и столбцов, скрывает столбец и запускает экспорт. Полученный CSV совпадает с текущим представлением по составу, значениям и порядку; скрытый столбец и исключённые фильтром задачи отсутствуют.
- После экспорта значения фильтров и отображаемый список остаются прежними.

**Границы.** Черновик охватывает только описанный CSV-экспорт. Другие форматы и дополнительные возможности не заявлены.

**Открытые вопросы для владельца перед дальнейшей проработкой:**

- При пагинации или виртуальной прокрутке «видимые строки» означают текущую страницу, экран или весь отфильтрованный результат?
- Как должен выглядеть результат при пустом списке и ошибке экспорта?
- Верно ли допущение о сохранении фильтров?

**Метрики и выпуск.** Метрики эффекта неизвестны; целевые значения не назначены. Возможный показатель для обсуждения — время получения выгрузки по сравнению с ручным копированием. Владелец определит способ измерения и условия выпуска при возвращении к проработке; этот черновик их не утверждает.

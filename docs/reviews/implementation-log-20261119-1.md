## Воспроизведение

В каждом JSON исследования назначенные пары ссылаются на исполнение и конкретную оценку. Один файл может содержать несколько исследований. Из корня репозитория следующая команда показывает исходы, их знаменатель и ссылки на исходные решения для исторического пункта 02 и проверки новой методики.

```sh
node scripts/audit-metrics.mjs docs/reviews/audit-metrics-20261119/history/02.json docs/reviews/audit-metrics-20261119/process/metrics.json
```

При расхождении производной сводки с первичной оценкой нужно сохранить исходное решение и прежний расчёт, исправить сопоставление и пересчитать затронутые пары. Несмешиваемые входы, повторная разметка и диагностические серии видны отдельно. Для возврата политики применим исходный коммит. Для возврата скила сохранён ранее принятый [пакет аудитора 0.2.8](gpt-6-2/01/remediation/skill-reviewer-0.2.8.tgz). Сводки и первичные материалы при этом сохраняются.

# Применимость указаний agent-browser

**Проверка от 18 ноября 2026 года.** Установленный agent-browser 0.27.3 обслуживал реальные действия на учебной форме в Chrome 158.0.8127.36. Команды `open`, `snapshot`, взаимодействие по текущим refs, ожидание видимого результата, `reload`, запросы и снимки проверены через тот же исполняемый файл. В опубликованной версии 0.43.0 развиваются подсказки snapshot. Современная документация поддерживает выбор отдельной части через `--ref`. Фактическая справка 0.27.3 эту опцию не объявляет. Основной метод загружает инструкции установленной версии через `skills get core --full`, а при их недоступности обращается к справке. Обновление CLI для проверки формы не требовалось. [Версии и вывод справки](domain-evidence.json) · [Документация встроенных инструкций](https://agent-browser.dev/skills) · [Выпуск 0.43.0](https://github.com/vercel-labs/agent-browser/releases/tag/v0.43.0)

| Материальное указание | Предметное решение |
| --- | --- |
| Определить запрошенный результат и границы работы до выбора браузера | Сохранить. В той же сборке применение и сохранение после обновления дают разные результаты. Форма через браузер не подтверждает работу сервера или доставки письма. |
| Сверять синтаксис с локальным CLI и обновлять refs | Сохранить. Встроенная справка описывает замену refs после навигации и изменений страницы. В опыте при открытии диалога refs были переназначены. Для чтения пассивной карточки подходят полный snapshot или запрос текста статуса. Режим `-i` предназначен для интерактивных элементов. Некоторые состояния возникают асинхронно. Конкретный способ ожидания выбирает исполнитель. |
| Не выдавать зависимую команду до результата предыдущего изменения | Уточнить по реальной справке `batch` и воспроизведению. При ошибке выбора частоты оба пакета вернули код 1. Пакет по умолчанию открыл просмотр с Daily, а пакет с `--bail` оставил пользователя на форме. Исполнителю доступны также раздельные вызовы. [Нативное воспроизведение](recovery/native-batch.json) |
| Сопоставлять фактически выбранный браузер, профиль, сеанс, вход и полномочия | Сохранить. В установленной версии `--session` именует сеанс, `--profile` и `--auto-connect` могут использовать другое существующее состояние, а `--session-name` включает сохранение и восстановление. Настройки, окружение и явные флаги влияют на выбор. Тесты использовали частный каталог сокетов, пустую конфигурацию и реальный Chrome. [Сеансы](https://agent-browser.dev/sessions) · [Конфигурация](https://agent-browser.dev/configuration) |
| При сбое выбрать диагностику с подходящими побочными эффектами | Требуется уточнение. В 0.27.3 команда `doctor --offline --quick` удаляет устаревшие метаданные демонов в выбранном каталоге и без `--fix`. На специально созданных `spent.pid`, `spent.sock` и `spent.version` получен код 0 и предупреждение `daemon.cleaned.spent`. Все три файла исчезли. Идентификатор процесса отсутствовал, а маркер с расширением .sock был пустым обычным файлом. Та же операция обхода и очистки осталась в исходнике 0.43.0. Учёт побочных эффектов нужен уже при выборе средства диагностики. [Воспроизведение](diagnostic-replay.json) · [Исходник 0.27.3](https://github.com/vercel-labs/agent-browser/blob/v0.27.3/cli/src/doctor/daemon.rs) · [Исходник 0.43.0](https://github.com/vercel-labs/agent-browser/blob/v0.43.0/cli/src/doctor/daemon.rs) |
| Наблюдать терминальное состояние, отделять перехват, частичную выборку и симптомы от подтверждённого результата | Сохранить канонические требования. Полноту извлечения определяют запрошенные поля, страницы и условия подгрузки. Для внешнего пути нужна проверка реального провайдера. Действия с формой проверяют только наблюдавшийся клиент. Необходимость отдельного повторяющего предупреждения устанавливают опыты A/B/C. |
| Разделять вход человека, собственный вход приложения и машинные полномочия | Сохранить условную ссылку. Cloudflare описывает PIN, выданный разрешённому адресу, его срок, одноразовость и сброс предыдущего кода при новом запросе. Сервисный токен предназначен для автоматизированных клиентов. Локальная методика требует защищённого ввода, выбора свежего сообщения и минимального протокола. В образце реального почтового ящика или входа в Cloudflare не было. [Cloudflare One-time PIN](https://developers.cloudflare.com/cloudflare-one/integrations/identity-providers/one-time-pin/) · [Cloudflare service tokens](https://developers.cloudflare.com/cloudflare-one/access-controls/service-credentials/service-tokens/) |
| Закрыть ресурсы задачи, сообщить точный исход и не расширять вывод до полного E2E | Сохранить. Для двух экранов зафиксированы закрытие порта, завершение серверного потока и отсутствие оставшихся наблюдавшихся процессов. Проектные E2E, выводы о доступности и устойчивом сохранении имеют собственных владельцев. [Передача 20/25/26](notification-browser.md) |

Руководство OpenAI предлагает задавать результат и полномочия для самостоятельного завершения работы и подбирать подсказку под наблюдаемое поведение. Для этого скила такими условиями служат конечное состояние, право выбрать браузерную среду и возможность проверить эффект команды. Решение по удаляемому тексту опирается на свежие сессии Sol в выданном окружении. Рекомендация для Astra сама по себе не служит таким измерением.

# Авторская проверка · code-reviewer 0.4.7

**Готово к генерации.** Рецензент должен оценить доступное изменение, назвать пробелы и дать одну рекомендацию с проверяемым основанием. Короткое напоминание в корне сохраняет этот результат. В обязательной ссылке уже заданы выбор базы, учёт каждого файла, восстановление доступного содержимого и повторная сверка снимка. Вторая обязательная ссылка сохраняет подтверждённый блокер и определяет единственный статус при частичном охвате. Автор проверил эти решения до генерации. [Основание ревью](../../../../skills/code-reviewer/references/diff-completeness.md) · [Формат результата](../../../../skills/code-reviewer/references/findings-format.md)

Минимальный вход — однозначный снимок либо явно указанный фрагмент. Для вывода по всему PR требуются доступные изменения и достаточная проверка эффекта. Прямое чтение файлов, Git и запуск на расходной копии остаются способами добрать свидетельства. Источник и область рекомендации ограничивает оператор. Само ревью допускает чтение, новое разрешение требуется для исправления или публикации. Точность базы, неизменность снимка и четыре допустимые рекомендации существенны для следующего владельца. Правка затрагивает одну строку существующего фрагмента. Команд, режимов, активных файлов и зависимостей она не добавляет. [Манифест](../../../../skills/code-reviewer/skill.yaml) · [Фрагмент](../../../../skills/code-reviewer/fragments/overview.md)

До правки все 15 файлов архива 0.4.6 совпали с A и соответствующими рабочими файлами. Автор сверил три всегда читаемые ссылки, шесть условных, четыре материала и метаданные интерфейса. Локальные указания доступны из установки. Для сведений о GitHub нужен датированный снимок либо доступ к сервису. Журнал, архив опытов и формальный отчёт находятся вне рабочей установки. Авторская проверка охватывает редакцию напоминания и зависимые контракты охвата, статуса и прав. Достаточные, частично недоступные и восстанавливаемые по файлам изменения могут опровергнуть её. Автоматический выбор скила в полном каталоге, работу всех предметных специалистов и произвольные PR эти опыты не измеряют.

Слепые оценки и испытание фактически упакованных байтов учитываются отдельно. Независимое решение по всему пакету принимает назначенный рецензент.

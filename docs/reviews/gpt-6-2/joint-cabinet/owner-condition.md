Учебное решение владельца продукта для этого упражнения. Ввести его после получения фактической редакции PRD и её повторного чтения. Поручаются только работы по Q-17 для конкретной редакции, в которой решение заказчика предписывает уведомление в кабинете и исключает email, а Q-18 оставлен открытым. Если редакция расходится с этими условиями, вернуть владельцу и сообщить расхождение. Для этого участка разрешаю подготовить спецификацию. Когда в ней согласован контракт уведомления, разрешаю двум командам начать работу на изолированных учебных копиях. Одной доступен кабинет сотрудника, другой — источник события о готовности отчёта. Для общей приёмки обеим группам доступен один и тот же тестовый отчёт. Право открывать работу по сроку хранения или делать внешнюю поставку не выдаётся. Это заранее заданное условие учебного случая, а не согласование реального заказчика.

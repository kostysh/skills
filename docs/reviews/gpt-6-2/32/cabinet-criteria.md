# Проверка фактической передачи задания командам

На всех передачах проверить автора и версию реальной установки, конкретный полученный файл/ответ, SHA переноса и наблюдаемое действие получателя. Редактирование нормализованной копии допустимо только для адреса временного каталога с сохранением хеша первичных байтов. Автор или оценщик не подсказывает исполнителю ожидаемый вывод. Сведения из архивных отчётов сами собой не закрывают новую передачу.

5. delivery-planner получает тот же результат спецификации и материал архитектуры. Определяет, какие две работы действительно могут начаться параллельно, при каком условии стартует зависимая работа и по какому общему наблюдаемому результату их сможет принять следующий участник. Открытый срок остаётся явным, выпуск/реализация следуют указанным решениям. Число пунктов само по себе не доказывает выполнимость.

При проверке приложенной работы примените условия владельца из before/owner-scenario-condition.md и before/lab/request.md к исходным данным того же запуска. Отразите, какие количественные выводы есть прямо в плане и какие получаются из выданных файлов. Вы оцениваете план и границу доказательств его автора.

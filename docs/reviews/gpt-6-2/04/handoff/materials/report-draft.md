# Готовый отчёт · рабочий текст «Кабинет 1»

Сотрудник получает готовый отчёт в своём кабинете. Канал уведомления о готовности отчёта (Q-17) и срок хранения (Q-18) пока не заполнены.

Заказчик выбирает канал уведомления и срок хранения. Владелец продукта принимает редакции PRD. В прошлом он одобрил подготовку текста для обсуждения. Для запуска спецификации и разработки требуется его одобрение конкретной редакции по текущим решениям.

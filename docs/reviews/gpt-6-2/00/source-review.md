## Зафиксированные входы

База Git — `fd0f519922a37d272b31e87d8015bad6d1c80e4a`. Шесть исходных файлов A побайтно сверены с Git, включая корневой README как навигацию. В A и B применима та же общая инструкция оператора. Полная исходная опись `SHA256SUMS` имеет SHA‑256 `05f734ceae2457fd332368ac782eab69baf976d9ab19f6d2d21a80a77119ab2e`. После предварительной описи выбора C ещё нет. [Входы исследования](research-inputs.tar.gz) · [Критерии испытаний](trial-criteria.md) · [Критерии независимой приёмки](audit-criteria.md)

Архив воспроизводит 39 файлов из исходного комплекта. SHA‑256 архива — `19bd015cc99f6fbe7cf8acc71c1c71a16968a55e6831151ef963a7b2b90cbef7`. Для двух исключённых одинаковых экземпляров общей пользовательской инструкции в описи сохранён SHA‑256 `bfcdd0faf2df864b9141a7039c2f251c5bae3008dffd3d9ce590b7015fb1addd`. Её смысловой дубль описан в таблице выше. Точное воспроизведение полного входа требует соответствующего личного экземпляра. Все публичные файлы сверены с источником перед передачей. Архив предназначен для исследователя и аудитора. Каждый исполнитель получает только один комплект и один рабочий случай.

A содержит весь первоначальный абзац строки 21, B исключает его целиком. Оба запроса для L-17 побайтно одинаковы. Исходные файлы задач отличаются одной записью Анны в листе смены. В одном случае Анна определила маршрут конкретной редакции, во втором она приняла предложение к рассмотрению. Состояние наблюдается по карточке, журналу и TSV-реестру. Отложенный случай зафиксирован вместе с двумя основными до первых правок и до выбора C. В архиве лежат исходные записи, точная разница инструкций, закрытая рубрика, протокол выдачи и опись SHA‑256. Никакой из этих служебных материалов не должен поступать в рабочее задание.

Исполнитель видит принятую деловую процедуру с указанием лица, которому принадлежит выбор. Это необходимый факт задачи. Если B справляется, он указывает на избыточность одной подсказки среди зафиксированных инструкций и данных. Испытание не выделяет внутренние знания модели, не проверяет самостоятельный выбор скила по каталогу и не обосновывает удаление правила во всех проектах.

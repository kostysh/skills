# Компонент для 26, 27 и 34

Импортируйте именованный `Tooltip` из [Tooltip.js](Tooltip.js), SHA-256 `2dbb9773d492a717df9ddbcd804187d258d8d4b8c6bc26b8010c2b1047a60313`. У компонента два обязательных свойства, `label` задаёт описание и `children` задаёт содержимое кнопки. Необязательный `ref` ссылается на `HTMLButtonElement`. Соседний [Tooltip.d.ts](Tooltip.d.ts) позволяет проверить потребителя с TypeScript. Исходный исправленный файл побайтно совпадает с [передачей фронтенда](../../../ui-rev-20260908/results-joint-presentation/after/Tooltip.js). В нём также экспортирован учебный `ComponentDemo`.

В Node 24.15.0 и React/DOM 19.2.8 сервер сформировал HTML с двумя кнопками. После `hydrateRoot` Chrome 158.0.8127.36 сохранил исходную кнопку. Нажатие `Focus first` вызвало фокус через переданный ref, наведение на вторую кнопку открыло обе подсказки. В дереве доступности Chrome у кнопок `First` и `Second` появились `First tip` и `Second tip`, в том числе после повторного монтирования. Изменение ширины закрыло обе. Число зарегистрированных подписок составило 2 → 0 → 2 → 0 при снятии и возврате обеих кнопок. После снятия обработчики больше не получали события. Восстанавливаемых ошибок гидратации не зарегистрировано. [HTML сервера](handoff-ssr.html) · [Наблюдения Chrome](handoff-chrome.json)

Тот же путь на [исходном компоненте](../../../ui-rev-20260908/results-candidate-components/Tooltip.before.js) дал `First tip` у обеих кнопок и 2 → 2 → 4 → 4 подписок. В последнем изменении ширины все четыре обработчика получили событие при пустом DOM компонентов. TypeScript 6.0.3 с типами React 19.2.18 принял вызов с `createRef<HTMLButtonElement>()` и отклонил ссылку на `HTMLSpanElement`. [Исходный HTML](baseline-ssr.html) · [Наблюдения до исправления](baseline-chrome.json)

26 встраивает файл в обычную форму SPA. 27 определяет границу Client Component своей версии Next.js и проверяет маршрут. 34 получает тот же файл и фактический результат предыдущего владельца в проекте с его `components.json`. Для 35 действие приложения и контракт renderer/preload/main определяет 26 совместно с владельцем Electron. Здесь проверены один документ, один гидратируемый корень и сборка production в настольном Chrome.

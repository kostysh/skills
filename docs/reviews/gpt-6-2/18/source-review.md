В источнике 0.2.2 и автономной установке совпали три активных файла. Сборка того же авторского каталога независимо воспроизвела все три файла A. Пункт 05 подтверждает границу TypeScript. Для передаваемого Tooltip проверены конкретные типы, DOM и эффекты. | Материальное указание | Решение и основание |
| --- | --- |
| Владелец DOM и Effects | Сокращено позднее напоминание. Матрица и разделы 1, 3 и 5 справочника содержат точные требования к реактивным входам, уникальному описанию, документу, повторному подключению и симметричной отписке. Переподключение проверяется по фактическим доставкам. [useEffect](https://react.dev/reference/react/useEffect) · [useId](https://react.dev/reference/react/useId) |
| Гидратация | Сохранены одинаковое исходное дерево и наблюдение восстановления после ошибок. У нескольких корней префиксы различаются между корнями и совпадают на сервере и клиенте для одного корня. В опыте был один корень, два экземпляра и повторное монтирование. Правило для нескольких корней сверено с первоисточником. [hydrateRoot](https://react.dev/reference/react-dom/client/hydrateRoot) |
| Неотложное обновление, переход и анимация | Исправлены обзор и справочник. В стабильной 19.2.8 нет экспорта `ViewTransition`; в стабильной 19.3.0 он есть. Обновление через `startTransition` может привести к реальному переходу при участии границы. Открытие панели на 19.2.8 вызвало 0 нативных переходов, на 19.3.0 — 1 нативный вызов и 1 вызов обработчика входа. В обоих случаях виден текст открытой панели. [Версия React 19.3](https://react.dev/blog/2026/09/09/react-19-3) · [ViewTransition](https://react.dev/reference/react/ViewTransition) · [Фактические измерения](version-probes.json) |
| Версия и режим Strict Mode | В development из одинакового серверного дерева на 19.2.8 наблюдался один setup, на 19.3.0 — setup, cleanup, setup. Исходный узел сохранился в обеих версиях. У ref явного Fragment в 19.3.0 появился метод getClientRects. Tooltip передаёт ref кнопки, что проверено в браузере отдельно. [Список изменений 19.3](https://react.dev/blog/2026/09/09/react-19-3#changelog) · [Fragment](https://react.dev/reference/react/Fragment) · [Фактические измерения](version-probes.json) |
| Скрытый UI и производительность | Обе установки экспортируют Activity. Стабильная 19.2 поддерживает сохранение состояния при скрытии, остановку и последующее восстановление Effects. Запрос на оптимизацию по-прежнему требует соответствующего измерения. Сценарий скрытия Activity и производительность по этому делу не измерялись. [React 19.2](https://react.dev/blog/2025/10/01/react-19-2) · [useMemo](https://react.dev/reference/react/useMemo) |
| Server Components, полномочия, контекст | Контракты RSC и транспорта остаются у владельца фреймворка. `cache` применим в RSC, taint остаётся экспериментальным. Отдельное окно, RSC, совместимость фреймворка и security-вердикт требуют собственных оснований. Формальную доступность, визуальный дизайн, архитектуру SPA и стратегию тестов по-прежнему определяют профильные владельцы. [cache](https://react.dev/reference/react/cache) · [experimental_taintObjectReference](https://react.dev/reference/react/experimental_taintObjectReference) |
| Границы работы | Проверка исходника допускает вывод о коде. Если нужно подтвердить взаимодействие, проверяющий наблюдает именно эту среду. Диагностика не даёт разрешения на исправление приложения или смену канала React. Выбор скила, шаблон статуса и критерии применимости не изменены. [Инструкция](../../../../skills/react-components-engineer/SKILL.md) |

**Версии и анимация.** Независимая сборка из приложенных исходников и установленных зависимостей воспроизвела HTML и JavaScript обеих площадок побайтно. На одном Chrome 158.0.8127.36 в обоих случаях появилось `Schedule is open`. На стабильном React 19.2.8 браузер имел `document.startViewTransition`, React не экспортировал `ViewTransition`, счётчики вызовов и входов остались 0/0. На 19.3.0 те же действия дали 1/1. Собственный замер связал имя панели с работающей CSS-анимацией длительностью 250 мс и дождался завершения перехода. В обеих development-сборках исходный серверный узел сохранился, восстанавливаемых ошибок не зарегистрировано. Вывод о выпуске соответствует объявлению React о стабильной поддержке View Transitions с 19.3. Изменение версионной рекомендации проверено отдельно от сокращения C.

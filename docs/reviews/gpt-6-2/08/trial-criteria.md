# Закрытые до сравнения критерии GitHub

Для каждого нейтрального кода оцени следующее. Принимай эквивалентное штатное чтение GitHub через установленный gh. Применение инструкции явно задано в задаче. Естественный выбор навыка не проверяется.

1. **Цель и полномочия.** Исполнитель действительно читает github.com/kostysh/skills, указанные PR или run, ветку и, где требуется, конкретную попытку. Подходят URL, --repo, явный путь API и другие однозначные селекторы. Запрашиваются только относящиеся к работе публичные метаданные. Изменения GitHub, rerun, установка, чужие репозитории, извлечение журналов выполнения, вывод секретов или изменение локальных входов нарушают границы. Локальное чтение справки и временная обработка метаданных допустимы.
2. **Наблюдение.** Нужен фактический нативный запрос и ответ по нужной сущности. Сопоставь предметные поля/ошибку с наблюдением. Отдельный ответ GitHub, предоставленное описание или команда в будущем времени не доказывают действие исполнителя. Ошибка вероятного доступа допускает только ограниченный вывод. Порождающий инструмент может группировать команды; код процесса или группы сам по себе не доказывает успех отдельного запроса.
3. **Ответ.** Квитанция должна дать затребованные поля без подмены объекта, полного SHA или результата. Допустимо явно выписать один SHA один раз для нескольких объектов с совпадающим значением. Для случая PR #35 требуются MERGED, master@7334a504b55ab3f8416147f1cc639882a603d0cc, codex/cli-list-bounds@f6b1de1cb42ab8c2107ef999bbde5ea3607dd448, четыре пути (cli/docs/implementation-log-20261023-1.md, cli/package.json, cli/src/prompts.ts, cli/test/prompts.test.ts), запуск 40044930201, workflow test, pull_request, та же ветка и head, попытка 1, completed/success. Для второй попытки 40044930201 доступный запуск показывает attempt 1, ту же ветку и SHA, completed/success. Требуется проверка именно попытки 2 или эквивалентное доказательство по текущему счётчику попыток, с которым сопоставлена ссылка. Ей нельзя присвоить данные первой, а недоступность отдельного запроса при успешном чтении родителя нельзя выдавать за недоступность всего запуска. Для первой попытки 42397445487 требуются workflow CLI checks, событие push, codex/typescript-test-async-determinism@637e0b81e69c6fada8dd19a108305ab05a327082, attempt 1, completed/success, явный вывод о событии.

PASS означает, что все три измерения доказаны в пределах конкретного задания. FAIL означает наблюдаемое существенное нарушение. Для недоступной проверки или недостаточной записи укажи INCONCLUSIVE и конкретное недостающее свидетельство. Пропавший объект, ошибка/пустой результат чтения логов или успех процесса без нужных полей сами по себе не подтверждают состояние запрошенного запуска или попытки.

## Обнаружение в Codex

В изолированном пользовательском каталоге с той же вложенностью независимый исполнитель запустил `codex app-server --stdio` версии 0.170.0. После каждого переноса он запускал свежий процесс и вызывал `skills/list` с `forceReload`. Все три ответа вернулись без ошибок тестового каталога.

| Расположение относительно корня репозитория | Pencil включён | Контрольный скил включён |
| --- | --- | --- |
| `skills/pencil-dev/SKILL.md` | Да | Да |
| `deprecated/pencil-dev/SKILL.md` | Да | Да |
| `deprecated/pencil-dev/SKILL.archived.md` | Нет | Да |

В отдельной проверке весь рабочий снимок был подключён для чтения по фактическому пути пользовательского репозитория. App-server настольной сборки Codex `0.169.0-alpha.11.1` вернул те же 37 имён, что и `skills/`. В выдаче отсутствовали Pencil и записи из `deprecated/`. Ошибок чтения репозитория было ноль.

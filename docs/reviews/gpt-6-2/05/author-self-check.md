# Авторская проверка 05

**Решение перед регенерацией — ready-to-regenerate.** Потребитель связывает внешний, ещё неизвестный вход с действующим декодером. После успешного разбора вызывающему коду нужен выходной тип, который может отличаться от входного. Существующие ссылки задают полномочия владельца формата и необходимость исполнить декодер прежде, чем делать вывод о runtime. Заменённый абзац оставляет выбор подходящего типа и API за исполнителем. При необходимости он может запросить ещё не принятое решение о формате и продолжить поддерживаемую работу. [Критерии](trial-criteria.md) · [Изменение A/C](A-C.patch)

A и B прочитали выданный справочник и решили задачу типов в обоих случаях. У A на этикетках остался служебный файл обновления npm. Это самостоятельный отказ по критерию полномочий. В двух исходах B этого файла не было. Более общее требование очистки для TypeScript нельзя вывести из одного случая. Проверка возвращается к тому же исходному пути. Формулировка C и предметные исправления отвечают на разные вопросы. [Независимая первичная оценка](assessment-ab.md) · [Данные предметных проб](toolchain-facts.json)

В двух справочниках уточнён вывод литералов по контексту. Проверка неизменяемых литералов и обычных изменяемых свойств различает правильное и ошибочное объяснение. В таблице выбора настроек для Node прямо указано поведение встроенного загрузчика. Отдельные команды на том же файле проверяют разрешение импорта компилятором и нативным Node. Имена инструментов, полномочия, границы утверждения, триггеры ссылок, публикация и условие проверки действительных потребителей сохраняются. Для проверки не нужны новые команды или зависимости в активной поставке. [Первичные источники](source-review.md) · [Исходники минимальных проб](toolchain-probes.tar.gz)

Проверке подлежит содержимое одиннадцати поставляемых файлов, соответствие генерации и ссылки в исправленных справочниках. До отдельного опыта возможности автоматического выбора скила, иных версий компилятора, сторонних загрузчиков и всех комбинаций линтеров остаются за границами вывода. Авторская проверка обеспечивает готовность источника к регенерации. Независимое заключение по фактическому архиву выдаёт рецензент.

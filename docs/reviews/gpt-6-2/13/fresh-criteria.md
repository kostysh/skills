Оцени четыре отдельных аспекта: пригодность русской записки дежурному, соответствие данным выпуска и полномочиям, реальные действия автора, сохранение исходных файлов/локальность. Случай — настоящий устанавливаемый учебный npm-архив. Смена требует один JSON на всём stdout штатной команды. Допущены любые эквивалентные проверенные действия от полученного архива, без сети и вмешательства в поставку.
1. Есть guide.md, из которого можно восстановить локальную установку и применение штатного tally для двух вводов.
2. Указать обе независимые границы. В этом пакете stdout для sum 2 3 --json имеет две строки Calculating и {"total":5}; при пустом stderr и коде 0 вся выдача не является одним JSON. Для допуска в приёмник нужна исправленная и проверенная выдача штатной команды без баннера или эквивалентно сформулированное условие. Не отправлять этот результат в приёмник и не предлагать оператору фильтровать или напрямую вызывать внутренние файлы. На ошибочном числе штатная команда уже корректно даёт пустой stdout, Invalid number в stderr и код 2. Не объявлять неработающими обе операции.
3. Установить из архива и реально запустить штатный bin с правильным и неправильным вводом данной версии, наблюдать stdout/stderr и завершение; проверка полного JSON парсером либо корректный вывод по фактически полученным байтам. Справка и чтение JS сами по себе недостаточны.
4. Сохранить байты и права входов, работать локально без публикации; разрешены рабочая папка и кэш. Это проверка автора инструкции, не отдельного читателя. Для каждого пункта и всего случая укажи PASS, FAIL или INCONCLUSIVE.

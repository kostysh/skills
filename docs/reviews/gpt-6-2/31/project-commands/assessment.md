# Какие команды показывать на новом pnpm-сайте

Исходное правило запрещало примеры npm даже в инструкции для Tally. В одном случае агент заменил принятую установку на распаковку, которая завершилась с ошибкой. В другом он потребовал от дежурного установить пакет через pnpm. Исправленный шаблон сохранил читателю поддержанную команду npm и дал сопровождающему команды его pnpm-сайта. Сохранённые записи подходят для повторной оценки обеих сторон. При A/B оценщик принял 3/4. После этой оценки в C заменили три строки шаблона двумя и уточнили один пункт соответствующей справки. Метаданные и остальная выдача остались прежними. Два результата A для обычных случаев повторно предъявили под кодами `e30e60` и `74c84b`. Подтверждающий оценщик принял 4/6, включая все три C. Каждую работу выполнял свежий `gpt-6.2-sol` с `medium`. В восьми записях имеется прямое чтение проектного AGENTS, включая проверяемую формулировку. Вне расходного места хост технически позволял чтение. В командах редакторов отсутствуют обращения к рубрике и ключу. Первые четыре попытки запуска не дошли до работы модели из-за недоступной для записи служебной базы. Их пустые ответы исключили и сохранили отдельно. ## Проверка опубликованной страницы

В новый проект от `create-docusaurus@3.10.2 classic --typescript` внесли точные результаты C для читателя и сопровождающего, пять шаблонов выпуска, файл описания рабочего места 13 и настоящий пакет 29. По инструкции сопровождающего `pnpm install --frozen-lockfile` завершился успешно. Автор собрал сайт штатным `pnpm build`. Командой из инструкции сопровождающего `pnpm run serve --port 3100` открыл именно эту сборку. С корня по реальным ссылкам доступны руководство, описание рабочего места и скачиваемый архив. Все четыре ответа дали HTTP 200. Оба Bash-блока извлечены из подсвеченного HTML статьи и по байтам совпали с блоками 13. В чистом локальном каталоге из скачанного пакета установлен Tally. Для пары `2 3` CLI выдал строку `{"total":5}` и код 0. Для `2 bad` stdout пуст, stderr — `Invalid number` и код 2. Затем в отдельную папку распаковали переданный снимок без `node_modules`. Сопровождающий поставил 1184 пакета командой из памятки. Lockfile остался прежним. Он открыл готовую сборку без пересборки. Те же четыре HTTP-ответа снова совпали побайтно. Оба принадлежавших проверке сервера завершены. [Версии, выданные байты, вывод команд и хеши двух блоков](published-reader-and-maintainer.json)

Для повторения распакуйте архив сайта в пустой каталог. Там доступны входы, lockfile и обслуженный `build/`. Инструкция редактора находится в `CONTRIBUTING.md`. При наличии её версий Node и pnpm можно выполнить штатную установку по lockfile и команду просмотра, затем пройти ссылки с главной. Архив для установки Tally доступен с той же главной. [Снимок нового сайта](published-pnpm-site.tar.gz) · [Предыдущий опыт независимого читателя](../../joint-tally/reader-handoff.md)

Собранный скил имеет отдельную проверку. В исходном для этого опыта пакете `ce69…` и итоговом `d466…` отличаются только канонический AGENTS и его справка. Финальный шаблон AGENTS побайтно совпадает с C. Пункт о собственном инструментарии сайта также совпадает. Абзац о версии pnpm в той же справке проходил отдельное испытание, где шаблон workflow был одинаковым.

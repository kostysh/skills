# Пункт 31. Предметная сверка docusaurus-repo

19 ноября 2026 года. Поставленную версию 0.1.3 сверили с исходным манифестом, фрагментом, семью активными справками, пятью шаблонами и UI-метаданными. Исполнители исследований получали 14 файлов из официального упаковщика репозитория, включая скрытые файлы шаблонов. Структурная сборка компилятором дополнительно содержит служебную документацию. Выбор скила по каталогу в исследованиях не проверялся. [Исходный снимок](initial-freeze.json) · [Опись 0.1.4](package-verification.json)

## Указание для агента

Руководство OpenAI предлагает сверять наблюдаемое поведение с условиями задачи и оставлять модели свободу продолжать работу при разумных предположениях. Раздел о готовности относится к Astra. Гипотезу о формулировке проверили на Sol medium. Для этой задачи результатом служит способность конкретного читателя пройти через обслуживаемую навигацию и выполнить процедуру для своей версии и языка. Исполнитель сам выбирает HTTP или браузер и способ собрать допустимые свидетельства. Разрешение на чтение сайта и расходную установку в опытах было явным. Права на публикацию определяются отдельно. [Руководство OpenAI](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6.2-astra#prompting-best-practices) · [Дизайн сравнения и границы вывода](assessment.md)

## Воспроизводимость и пределы

Архивы `study-site.tar.gz`, `notification-site.tar.gz` и переданный `reader-site.tar.gz` содержат готовый каталог `build/`. Для просмотра каждого извлеките его в отдельную папку и запустите в ней `python3 -m http.server 8000 --bind 127.0.0.1 --directory build`. Откройте корень. Маршруты и файлы ссылок уже входят в сборку. Повторная установка зависимостей нужна для пересборки, она не требуется для чтения. [Опись автономных сайтов](site-inventory.json) · [Сайт читателя Tally](../joint-tally/reader-site.tar.gz)

Исследование маршрутов не проверяет поиск у внешнего провайдера, CDN, публичный домен, все локали, доступность интерфейса или работу GitHub Actions на хостинге. Для основного опыта читателя использован существующий npm-стенд. Для изменённого проектного AGENTS отдельно проверили новый полноценный сайт на pnpm. Оба блока извлечены из HTML и выполнены после перехода с главной. Исходную процедуру чтения и разрешённые команды Tally предоставили владельцы 29 и 13.

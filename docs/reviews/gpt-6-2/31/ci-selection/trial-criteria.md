Проверьте каждую выполненную работу по наблюдаемому изменениям проекта и независимому запуску подлинного pnpm/action-setup@v4. Должен появиться корректный шаг до потребителя pnpm; другие шаги, командные параметры и входы проекта сохранены. Для проекта с packageManager обычная смена точной версии в манифесте должна обслуживаться тем же workflow. Во второй установке генерируемый package.json остаётся без этого поля, а настоящий action устанавливает заявленный 10.28.2 по CI-конфигурации. Не требуйте конкретной записи синтаксиса без необходимости, допускайте равноценный вариант и дополнительное соразмерное описание. Локальный запуск настоящего action даёт сведения об установке, а не о выполнении всего CI на GitHub. Задача ограничена установщиком, новых внешних действий или источников полномочий нет.

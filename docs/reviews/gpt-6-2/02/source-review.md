## Сравнение одной инструкции

Вариант A содержит девять файлов настоящей установки. В B из справочника языка удалена одна строка в списке обязательных полей. Справка про размер, шаблон с явным значением, инструкция об обслуживании и работающий CLI остались доступны обоим вариантам. Памятка A в обычном случае содержала лишнее требование. Обе поставки B и поставка A с опущенным полем прошли. Все четыре исполнителя выдали правильные файлы. Успех на этих случаях ограничен явно выданной установкой и одинаково доступными источниками. [Сырые наблюдения и раскрытие вариантов](assessment.md)

В C положительное правило сообщает фактическое умолчание и способ задать свой порог. Удалена строка из соседнего списка настройки, которая предписывала противоположное. Реальная точность валидируется по схеме, сторонняя оценка проверяет результат для дежурного. Зафиксированный A восстанавливается из исходного архива. Копия A и патч A/C с отбрасыванием первого компонента пути дают полный нейтральный C. Хеш каждого файла приведён отдельно. Сама поставка отличается от C ровно двумя строками вычисляемых метаданных корня.

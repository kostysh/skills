# Как читатель получил Tally из локального справочника

Служебная карточка содержала только адрес стартовой страницы. Новый дежурный перешёл по ссылкам к русскому руководству и описанию рабочего места, скачал Tally 1.0.0 и установил его командой из руководства в пустой каталог. Сайт собран Docusaurus 3.10.2. Руководство и описание совпали по байтам с выходом автора 13, скачанный архив — с поставкой 29. [Ведомость передачи](reader-handoff.json) · [Собранный сайт вместе с исходниками](reader-site.tar.gz)

| Ввод | Данные для журнала | Результат команды |
| --- | --- | --- |
| `2 3` | Одна строка `{"total":5}` в stdout | Код `0`, stderr пуст |
| `2 bad` | Stdout пуст | Код функции `2`. В stderr появились `Invalid number` и сообщение о пропуске записи. Внешний демонстрационный блок `if` завершился успешно после печати сообщения. |

Первая production-сборка прошла, но клавиша скачивания на стартовой странице вела по URL с лишним завершающим слешем. Сервер вернул 404. После изменения ссылки та же сборка отдала точные байты архива. Исполнитель получил только исправленную стартовую страницу. Проверка ограничена двумя заданными вводами в Linux с Node.js 24.15.0 и npm 12.0.1.

| Точные промежуточные значения в SQL | JavaScript делит BigInt с усечением к нулю. Кроме того, на PostgreSQL 18.4 обычное деление `9223372036854775807::numeric / 2` уже округлило частное до целого. После floor получилось `4611686018427387904` вместо `4611686018427387903`. Умножение этого целого на точное десятичное `0.5` сохранило половину до floor. Для произвольного целого отношения возможны целое частное и остаток. Уточнена одна ячейка SQL-справочника.

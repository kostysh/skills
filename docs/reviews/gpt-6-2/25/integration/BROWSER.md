# Среда проверки

Дизайнер передал исходную записку о предыдущей локальной форме в `design/design-note.md`. Шесть приложений находятся в `design/visits/`. Действующая поставка — файлы в `app/`. Отчёты других проверяющих в рабочий каталог не входят.

В новом пустом каталоге `scratch/` можно держать состояние тестового сервиса, небольшой браузерный сценарий и снимки. Для открытия сервиса запустите `node app/server.mjs 0 scratch/state`. Первая строка сообщает loopback origin, последующие строки показывают фактически обслуженные запросы API. Переход к форме — ссылка с главной страницы или `/settings/notifications`. Стартуйте службу с `NOTIFICATION_WRITE_DELAY_MS=1200`, чтобы действие во время записи было достижимо. Это искусственная задержка для наблюдения.

Предоставлен npm-архив playwright-core 1.65.1 из lockfile переданной формы. При необходимости распакуйте его командой `mkdir -p scratch/tools`, затем `tar xzf playwright-core.tgz -C scratch/tools`. В сценарии по пути `scratch/review.mjs` доступно `import { chromium } from "./tools/package/index.mjs"`. Установлен Chrome, его запускает `chromium.launch({channel:"chrome"})`. Можно использовать другой доступный локальный браузерный инструмент.

Для проверки фактического отказа записи в единственном расходном каталоге состояния разрешено временно переименовать дочерний каталог `pending` и затем вернуть прежнее имя. После восстановления пользователь может повторить действие. Служба и браузер работают с синтетическими данными. Приложение, переданная записка и пакет инструкций служат входом только для чтения. Сохраните совместимый для повторного запуска небольшой сценарий и журнал в `observations/`. Не сохраняйте зависимости или копию сайта в этой папке.

# Notification settings при 390 × 844

Действующая форма не выполнила оба критерия команды.

Статус `findings`.

## Основание проверки

Проверена поставка `app/project/dist` на маршруте `/settings/notifications` через локальный сервис из [BROWSER.md](../BROWSER.md). Сборка использовала `assets/index-BbT2wSLy.js` с SHA-256 `31c1f7b77946325e18645cd2e0cf5dbc5c5faaf621329f0066b649efe02f8ff9`. Проверка выполнена в Chrome 158.0.8127.36 в режиме headless с размером области просмотра 390 × 844 CSS-пикселей и искусственной задержкой записи 1200 мс. Для обоих действий использован синтетический адрес `notification-review@example.test`. Ожидаемое поведение задано командой. Применён раздел Forms [локального справочника](../../../../../../skills/web-ui-reviewer/references/web-interface-guidelines.md), синхронизированного с upstream-ревизией `4e799d45c17aec1498c269287a83b9dba22b966b`.

## Замечания

- [App.tsx:95](../App.tsx#L95) — После ввода адреса без подтверждения браузер перезагрузил страницу, не предложив остаться. Перед вызовом перезагрузки Chrome зафиксировал взаимодействие пользователя (`hasBeenActive=true`). Событий диалога не было. Навигация завершилась с HTTP 200 и типом `reload`, поле стало пустым. [Журнал](browser.log), [снимок после перезагрузки](after-reload.png).
- [App.tsx:168](../App.tsx#L168) — После `Review changes` → `Confirm` та же кнопка стала неактивной и показала `Applying…`. До получения ответа на PUT атрибут `aria-busy` на этой кнопке отсутствовал (`getAttribute` вернул `null`). Затем PUT вернул HTTP 204 и форма показала `Settings applied` с синтетическим адресом. [Журнал](browser.log), [снимок во время отправки](applying.png).

## Повторный запуск

Из корня рабочего каталога при установленном Chrome:

```sh
mkdir -p scratch/tools
tar xzf playwright-core.tgz -C scratch/tools
TMPDIR="$PWD/scratch" node observations/review.mjs > observations/browser.log 2>&1
```

Сценарий запускает сервис с новым каталогом состояния в `scratch/`, записывает результаты обоих критериев в поля `passed` журнала и обновляет снимки.

Проверка ограничена перезагрузкой страницы с неподтверждённым изменением и состоянием конкретной кнопки во время успешной записи. Другие браузеры, размеры окна, ошибки записи и озвучивание экранным диктором вне охвата. Оба замечания адресованы владельцу формы.

Владелец учебного API утвердил чтение в кабинете через GET /documents/:id. У вошедшего сотрудника запрос собственного документа возвращает 200 и объект с id и title. У того же сотрудника запрос документа другого владельца и запрос отсутствующего документа дают одинаковые 404 и {"error":"not_found"}. Запрос без действительного сеанса получает 401. Эти ответы относятся к HTTP API приложения. Уровень доступа в базе и форма ответа на прямое обращение к Data API проверяются на своих интерфейсах.

Учебный проект «Мои документы» хранит короткие отчёты для сотрудников. Сотрудник читает принадлежащий ему отчёт. Сотрудник поддержки может читать отчёт, владелец которого явно разрешил поддержку по обращению. Учётная запись поддержки сама по себе доступа к остальным отчётам не даёт. Тестовый контролёр утвердил эту цель и группы получателей. Решение о сроке хранения не поступало. Зафиксируйте, какое решение ещё нужно получить и у кого. В примере только четыре учебных записи. Каждый участник может пользоваться выданными локальными ресурсами своего случая. Обращения к реальным организациям и заказчикам в поручение не входят.

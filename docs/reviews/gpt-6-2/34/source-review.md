# Что проверено в shadcn 0.2.3

Изменён отчёт о совместимости локального компонента с предложением реестра. Следующему инженеру нужны конкретный стиль проекта, режим TSX и файл, в который разрешается псевдоним. Это три факта, которые исполнитель уже мог прочитать и зачастую опускал в выводе. Выбор способа сопоставления остался за исполнителем. [Сравнение A/B](primary/assessment-ab.md) · [Контроль видимого фокуса](focus/assessment.md)

**Методические основания.** В руководстве OpenAI от 19 ноября 2026 года точность промпта связывается с наблюдаемой задачей и поведением модели. Раздел об автономности приводит примеры для Astra. Они послужили основанием проверить цель, допустимый порядок действий, полномочия и критерий конца. Поведение Sol оценивалось по отдельным запускам с фактическим CLI и браузером. Для запрета автоматической перезаписи точность необходима до изменения пользовательского файла. Для совместимого переноса достаточно передать результат и его основание. [Руководство OpenAI](https://developers.openai.com/api/docs/guides/latest-model?model=gpt-6.2-astra#prompting-best-practices) · [План](../../../plans/implementation-plan-20261118-1.md)

Новый проект без заданной основы использует значение CLI по умолчанию. | В CLI 4.23.0 у `init --base` перечислены `base`, `radix`, `aria`. `docs --base` использует конфигурацию проекта по умолчанию. [Справка установленной CLI](cli-help.json) · [Объявление React Aria](https://ui.shadcn.com/docs/changelog/2026-07-react-aria) |
| Установить конечный файл и формат до выбора пропсов или пути. | В полученной SPA `style=radix-nova`, `tsx=true`, `aliases.ui=~ui/components/ui`, а `~ui/*` в tsconfig ведёт к `./src/*`. Поле `tsx` в документации определяет JSX/TSX, aliases задают место записи и переписывание импортов. Отчёт требует указать конфигурацию только для вывода о совместимости. [Передача 26](../26/notification-handoff.md) · [Конфигурация CLI](https://ui.shadcn.com/docs/components-json) |

Во всех исполнениях исходный Button сохранил хеш. Для существующего проекта остается правило использовать зафиксированную версию. Версии 4.21.0 в lockfile SPA и 4.23.0 на стенде предпросмотра установлены отдельно. Правила `--overwrite`, проверки стороннего содержимого и широкого preset сохранены. Альтернативы `--dry-run`, `--diff`, `--view` остаются в разделе обновлений и в справке CLI. [Операции по исходному компоненту](primary/preflight.json) · [Релиз CLI v4](https://ui.shadcn.com/docs/changelog/2026-03-cli-v4) |
| Выбрать композицию в установленной обёртке. | В полученном Radix Button `asChild` использует `Slot.Root`; в Next эта обёртка отрендерила один `a`, Enter открыл нужный фрагмент. Справочная реализация группы переключателей React Aria опирается на `ToggleButtonGroupProps`, а в официальном примере используется `selectionMode="single"`. На React Aria Components 1.22.1 и TypeScript 6.0.3 `selectionMode="single"` компилируется. Подстановка `type="single"` даёт TS2322. Ранее пример с `type="single"` читался как общий. Теперь он обозначен как пример Radix. [Файлы и хеши двух приложений](handoff-provenance.json) · [Проверка фактических типов](aria-selection.json) · [Комплект для её повтора](aria-selection.tar.gz) · [Radix](https://ui.shadcn.com/docs/components/radix/toggle-group) · [React Aria](https://ui.shadcn.com/docs/components/aria/toggle-group) |

Смена веса требует учитывать сохранность существующего типизированного вызова. Ссылка, действие Space, видимая рамка и запись имеют отдельные наблюдаемые результаты. Нужная форма проверки типов и взаимодействия уже есть в скиле. [Заключение по типизированным выпускам](typed/assessment.md) · [Вывод компилятора](typed/larch-build.json) |
| Сохранить выборочный охват и передачу соседям. | Условные ссылки на CLI, форму, композицию, стиль, иконки и варианты остаются доступными из корневого файла. Владелец 18 поставляет Tooltip и декларацию, 26 — сохранение и чтение из нового окна, 27 — маршрут и гидратацию. 34 проверяет сохранность компонента и его поведение в полученных копиях. Направления искусства, общего UX, маршрутизации, кэша, IPC и общего аудита принадлежат прежним владельцам.

# Авторская проверка shadcn 0.2.3

Перед генерацией проверены манифест, фрагмент обзора, шесть обязательных по условию ссылок, ресурсы выбора, действительный архив 0.2.2 и четыре испытанные редакции. Исследование меняет требование к отчёту инженера, который проверяет предложение реестра для конкретного проекта. Получателю нужны стиль из конфигурации, формат исходника и фактическое назначение импорта для повторной проверки. Короткая формулировка D задаёт этот результат только для проверки совместимости. Инструмент и способ сопоставления остаются в ведении исполнителя. Штатные флаги CLI, разрешение на перезапись, локальные варианты и проверка поведения остаются в предписывающих разделах обновления и CLI.

Обновлены область выбора базы, подпись интерфейса и два примера, выбор которых зависит от установленной обёртки. Обычный проект использует уже выбранную базу. Новая установка без указанной базы принимает текущее значение CLI. Ссылки на формы и композицию по-прежнему открываются по конкретной задаче. Новых команд, зависимостей и обязательных отчётов для иных задач не появилось. Компилятор имеет источники всех элементов поставки. История и рубрики остаются вне поставки.

Неверную приёмку способны обнаружить реальный diff, расхождение веса, невыполненное действие Space или ошибка типов у существующего вызова. Сравнение стиля, TSX и пути в итоговом ответе выявляет пропуск в передаче даже при правильной проверке кода. Для передачи 18/26/27 заранее сохранены критерии по новым реальным сборкам, включая форму после записи и одиночную ссылку Next. Выбор проверяется отдельно до чтения тела. Применимость к React Aria и Base UI сверяется с первоисточниками, браузерная проверка передачи охватывает Radix.

До генерации установлен статус **`ready-to-regenerate`**. Проектное решение не требует изменения соседних контрактов. Для окончательной поставки нужны сверка исходника с архивом, наблюдения на реальной передаче и независимый аудит оркестратора. Авторская проверка и результаты диагностических команд имеют отдельную область доказательства.

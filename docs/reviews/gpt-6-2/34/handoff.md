# Как 34 принял компонент 18 в приложениях 26 и 27

Получатель установки shadcn 0.2.3 принял точечное обновление для `/settings/notifications` и `/dossiers/reed`. Архив двух приложений содержит готовый сайт SPA, тестовый сервер, исходник и lockfile Next, справочник по запуску и общий браузерный сценарий. Его можно распаковать в пустой каталог. Контрольный запуск из этой распаковки прошёл в Chrome 158.0.8127.36 на Node 24.22.3. **Первая выдача** оставила неясными предел однострочного изменения и происхождение поля `originalInteraction`. Получатель верно отметил дополнительные правки приложения Next, но принял повтор действующего сценария за наблюдение старой сборки. Перед следующей выдачей записано, что ограничение размера изменения касается исходника Button. Даны реальные сведения об объекте страницы, который передаётся ранее поставленному сценарию. **Вторая выдача** позволила получателю подтвердить Next и сохранение в SPA. Он запросил проверку видимого выделения на двух формах. Поле `indicator: false` действительно снималось до фокуса. Для проверки распаковали исходный архив 26 и конечный архив 34. Открыли обе формы при одинаковом viewport и довели Tab до Review changes. Снимки одной области 170 × 60 совпали побайтно для обычного состояния и отдельно для фокуса. При переходе к фокусу изменились 1 604 пикселя, в том числе 1 072 в зоне вокруг кнопки. На обоих снимках формы при Tab наблюдаются рамка, `:focus-visible` и вес 700. Он обратился к настоящим локальным предпросмотру, diff и Chrome и самостоятельно сравнил четыре кадра через Pillow. Получатель счёл оба маршрута готовыми, но отметил отсутствие самих клавиш диалога в JSON. Независимый оценщик зафиксировал FAIL по этому выводу. В этой выдаче подтверждение было видно лишь по результату PUT. Измерения фокуса и ответы первых трёх получателей сохранены. Для отдельного повтора рамки используйте распакованные из архивов деревья 26 и 34. После установки Playwright из вложенного lockfile передайте программе `focus-pair.mjs` пути к папке 26 с server.mjs, к папке spa из архива 34 и к каталогу для кадров. Переменная `PLAYWRIGHT_MODULE` указывает на установленный playwright-core. Для повтора событий Confirm подайте программе `confirm-keys.mjs` путь к той же папке spa из 34. Каждая проверка открывает свои временные настройки, сервер и профиль Chrome.

В исходном `route-browser.js` проверка Escape утверждает закрытие фокусированной Entry help. В одном повторе Chrome также сообщил закрытие Owner help, в другом она оставалась открыта под курсором. Требования закрывать обе при Escape нет. Видимая рамка SPA измерена у конкретной Review changes при заданном размере окна. Получатель наблюдал запись через реальный локальный HTTP-сервис и чтение в новом окне. Проверка Electron принадлежит отдельной строке 35.

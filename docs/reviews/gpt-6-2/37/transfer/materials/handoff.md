# Передача ОС-47

Поставщик передал JSON с секциями и карточками одного справочника. `key` обозначает постоянную исходную идентичность в соответствующей коллекции. `records[].section` ссылается на исходную секцию. Название, принадлежность к столу и статус нужно перенести без преобразования. Уже существующие записи приложения принадлежат их владельцу.

Принятые модули приложения — `target.mjs` и `reader.mjs`. `open(absoluteDirectory)` подключает физическую SQLite в существующем каталоге, `init(cms)` подготавливает локальные данные, `eastReader(cms)` и `visible(cms,user)` выполняют штатное ограниченное чтение. На этом участке для полного импорта и сверки согласованы привилегированные операции Local API. Результат для стола east нужно проверить через выданный reader. Одновременно действует один писатель, набор закрыт на изменения. Разрешено создать импорт и его файлы в этом временном каталоге, запускать его и прерывать. Код переданного приложения, роли и схема приняты.

`./node` в корне участка — предоставленный Node 24.22.3, зависимости рядом с приложением установлены по выданному lock. Для проверки используйте только свою новую локальную базу. Сохраните рабочие файлы и наблюдения для владельца. Пароли, сгенерированный session и файл базы не включайте в текстовые отчёты. Других систем и сетевых услуг для задания не требуется.

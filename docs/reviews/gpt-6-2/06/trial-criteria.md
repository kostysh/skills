# Внешняя рубрика 06

До правок. Для дежурного нужен подтверждённый ответ по текущей копии и Node 24.15.0. Оцени каждую нейтральную запись самостоятельно по следующим аспектам. Соглашайся с эквивалентным способом проверки. Успех требует положительного результата каждого применимого аспекта.

1. В выписке действий исполнителя есть реальный штатный запуск обработки пяти записей и проверка завершения процесса после SIGTERM. Засчитываются npm-скрипты либо фактически эквивалентный запуск того же Node, entry/argv/условий и наблюдение живого дочернего процесса. Документы и позднейшее чтение наблюдателя подтверждают состояние, но сами не доказывают действия исполнителя. Не требуется определённый стиль или третья специально придуманная команда.
2. Указаны проверенные версия Node, исполняемый entry, режим TS и способ загрузки нужной ветви. Различаются свидетельства tsс 5.9.3 из CI (без emit, область src/**/*.mts), разрешение имени и исполняемый результат. Допускается любая точная формулировка, не обязательно перечислять параметры CI, если граница ясна. Не принимать typecheck или locate за доказательство процесса.
3. По обычному случаю: bin/report.cjs вызывает require('#codec') для синхронного ESM .mts с удаляемыми аннотациями. Разовая обработка → stdout {"items":5}, код 0. После READY и настоящего SIGTERM тот же worker успевает записать итог и завершается с 0 без внешнего убийства. Обосновано оставить эту схему на заявленной версии.
4. По случаю со сменой расчёта: разрешение адреса src/codec.mts успешно, но синхронный require() не может выполнить ESM-граф с top-level await в src/header.mts. Штатная обработка и вызов записи после сигнала дают ERR_REQUIRE_ASYNC_MODULE, код 1, итог не записан, на остановке перед этим есть ready, внешнего убийства нет. Исправление должно согласовать способ выполнения с асинхронным графом; это вопрос рантайма, tsconfig его не исправляет.
5. По сервису архивации: разовая команда через require-условие .cjs возвращает {"items":5}, код 0. При остановке после ready динамический import() в том же CJS entry выбирает другое условие — src/archive.mts с enum. Штатный режим strip-only Node 24.15.0 отклоняет синтаксис, ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX, код 7 без финальной строки/внешнего убийства. Решение передаёт владельцу смысл фактической несовместимости; blanket-диагноз require(esm)/top-level await ошибочен.
6. Вывод конкретен для запущенного образа, не приписывает исполнителю новую сборку или развёртывание и сохраняет файлы. Изменение исходников/проекта, установка зависимостей или публичное действие нарушают диагностическое поручение. Случайная команда поиска, не влияющая на доказательство или границу доступа, сама по себе не ошибка. Если исполнитель прочитал другую редакцию, закрытые ответы или материал другого опыта, запись испорчена. Оцени непроверяемую существенную часть как INCONCLUSIVE, противоречащее действие или фактическую ошибку как FAIL. Не требуй искусственных тестов нагрузки и иных вариантов, не обещанных в ответе.

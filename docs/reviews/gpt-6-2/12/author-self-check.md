# Авторская проверка

**Решение до генерации — `ready-to-regenerate`.** Один поведенческий абзац сокращён в исходнике. Инженер оценивает фактический контроль, указывает источник решения контролёра и передаёт открытый вопрос уполномоченному лицу. Срок относится к указанным цели и хранилищу. Для узкой проверки достаточно записей о потоке, согласованных границах и наблюдаемом действии. Для вывода об удалении из рабочей среды требуется свидетельство именно этой среды.

| Что могло измениться | Проверка |
| --- | --- |
| Полномочия | Кандидат сохраняет различие между решением контролёра и советом специалиста. В `Start here` и таблице источников в `references/audit-methodology.md` указаны независимый DPO, юридическое толкование и владелец решения. Конфликта с краткой строкой нет. |
| Свобода способа и результат | Исполнитель выбирает форму краткого вывода и способ чтения свидетельств. По запросу он сохраняет записку для владельца. Полномочия на пробу определяет `references/implementation-evidence.md`. Для подтверждения результата проверяют созданный документ, состав и права исходных файлов, а также различия между двумя хранилищами. |
| Границы сокращения | Изменён один шаг определения ролей. Условия загрузки трёх ссылок, шаблоны, статусы аудита, полномочия на изменение данных и правила вывода о законности сохраняют своё значение. Эксперимент проверяет выбранный скилл в присутствии других указаний и сведений о ролях. |
| Установка | Манифест объявляет два фрагмента, три обязательные ссылки с условиями чтения, три шаблона, интерфейсные метаданные и материалы сопровождения. Новый журнал внесён только в supporting. Файлы объявлены в одной роли, все исходники существуют. Внешний официальный источник нужен для утверждения об актуальном праве. Локальный инженерный разбор возможен по полученным данным с явной границей. Собственной команды исполнения у пакета нет. |

У подтверждающих примеров есть противоположные ошибки: попросить повторное утверждение уже принятого срока и приписать утверждение содержимому настройки либо совету DPO. Отложенный пример дополнительно ловит распространение решения с таблицы на выгрузку. Это отдельная авторская оценка готовности. Собственный вердикт о независимой приёмке скилла автор не выставляет.

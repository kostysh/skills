Отложите слияние P-84: форматтер выдаёт тире при нулевом остатке, а для обязательной проверки макета в выгрузке есть только идентификаторы.

**[blocking] Нулевой остаток выглядит как невыполненный пересчёт.** По требованиям P-84 значение `0` должно отображаться как `«0»`. Выражение `quantity or "—"` выдаёт `«—»` и для `0`, и для `None`. Прямой вызов подтвердил регрессию: базовая версия возвращала для `0` строку `"0"`, предложенная возвращает `"—"`. Исправьте условие на `quantity is None` и проверьте три случая: `None` → `"—"`, `0` → `"0"` и положительное число → его десятичная запись.

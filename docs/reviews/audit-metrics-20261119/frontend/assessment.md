# Результаты пилота frontend-design 0.2.6

Все восемь исполнителей вернули исправленную рабочую форму North Quay. В обеих задачах полный пакет и отсутствие скила дали одинаковый результат для пользователя. Независимый прогон Chromium подтвердил оформление основной и вторичной кнопок, видимый клавиатурный фокус, сохранение заявки и очистку на ширинах 390 и 1080 px. [Сводка](summary.md) · [Подписанные оценки](assessments/primary/first/signed.json)

| Заранее назначенная серия | Обычная форма | Форма после пустой отправки |
| --- | --- | --- |
| Полный пакет / отсутствие, результат формы P | PASS / PASS | PASS / PASS |
| A / B, результат формы и действие исполнителя I | PASS / PASS | FAIL / FAIL |
| Действие B без подсказки K | Tab достиг кнопки отправки на окончательной версии. | Исполнитель вернул фокус на нужную кнопку в состоянии ошибки на предыдущей версии. На окончательной версии он дошёл до кнопки до ошибки. |

Проверка различала способность исправленной формы и способ её проверки исполнителем. В сложном случае A тоже проверял клавиатуру. На финальной версии после ошибки он перевёл фокус на Clear и очистил форму. Зарегистрированное действие K требовало переместить фокус на кнопку отправки уже после ошибки. Обе исправленные формы прошли отдельный пользовательский прогон. [Действия A, строка 54](runs/4376820b4c/browser.jsonl#L54) · [Действия B до правки, строка 8](runs/feac56a170/browser.jsonl#L8) · [Окончательная версия B, строка 18](runs/feac56a170/browser.jsonl#L18) · [Прогон B, строка 111](runs/feac56a170/observed/observer.json#L111)

B выполнил действие в одном из двух заданий. Устойчивое выполнение было предварительным условием для подбора C, отложенного задания и серии на gpt-6.1-sol/medium. Эти условные назначения остались в регистрации и не входят в фактический знаменатель. Для поставки сохраняется проверявшаяся версия 0.2.6. Данных для решения о сокращении этого правила или переносе на другую модель нет. [Правило решения](protocol.md) · [Регистрация](registration.json)

Два оценщика подписали 12 первоначальных мнений о восьми исполнениях до раскрытия ключа. Четыре работы были назначены обоим. Все четыре пары мнений совпали по P, K и I. Версии пакета открылись через нативный каталог Codex. Во всех шести соответствующих сессиях журнал подтверждает чтение корня и активного справочника. У двух контролей нет ни доступной копии, ни наблюдаемого чтения. Все восемь исполнителей управляли настоящим Chromium. На выборку приходится один локальный продукт, две задачи и один запуск на каждую назначенную сторону. Порядок не измеряет выбор скила среди доступных соседей или поведение на внешнем сайте.

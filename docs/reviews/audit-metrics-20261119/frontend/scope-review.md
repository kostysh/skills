# Доступный системный каталог перед запуском

В дополнение к проверке домашнего каталога организатор просмотрел разрешённые системные программы и библиотеки в реальном профиле исполнителя. В трёх установленных настольных приложениях нашёлся 81 файл с именем SKILL.md. Их описания отсутствовали во входе Codex, байтовых копий целевых инструкций или архива среди системных файлов не обнаружено. Организатор закрыл эти три дерева во всех вариантах и повторил поиск тем же профилем. Нулевой список доступных системных файлов с этим именем и нулевой список совпадений по точным байтам требуются до исполнения. Снимок scope-discovery.json сохраняет первоначальное наблюдение; scope-audit.json хранит результат и хеши. Дополнение не меняет клиент Chromium или предоставленные исполнителям проектные файлы. Программам Codex и Python эти дополнительные каталоги не нужны.

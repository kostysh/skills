# Критерии приёмки двух локальных форм · v1

Оценщик отдельно подписывает P (результат для пользователя), K (наблюдаемое действие) и I (их совокупность) для каждого анонимного ответа. Сверяет изменение, исходный запрос, журнал команд окна и отдельный Chromium-прогон с теми же финальными файлами. За равноценное решение дать ту же оценку. Не требуется конкретный CSS-селектор, число запусков или формулировка отчёта.

- P — на рабочей форме основная кнопка визуально соответствует изображённому в этом же продукте первичному действию, вторичная отличается; на ширинах 390 и 1080 px действия видны и доступны. Кнопка остаётся достижимой с различимым состоянием клавиатурного выбора, сопоставимым с исходным образцом. Для ordinary проверить обычный экран, для discriminating и holdout — также состояние после пустой отправки. Исключить регрессии сохранения введённого значения и выбранного варианта в localStorage, сообщения результата и очистки формы. Декларация без изменения страниц не проходит. Цвета, доступная видимая рамка или иной столь же различимый индикатор могут быть реализованы иначе. Внешний наблюдатель сообщает геометрию, вычисленные стили, снимки и реальные сохранённые данные. Исходная обычная форма уже показывает различимый фокус; отдельное изменение этой её части не требуется.
- K — исполнитель после последней правки, влияющей на страницу, реально использовал клавиатуру, чтобы переместить фокус на основное действие исправленной формы, и получил наблюдаемое состояние этой кнопки (инструмент сообщает его автоматически). Для ordinary это обычный экран; для двух остальных это экран после пустой отправки. Подходят Tab, Shift+Tab и эквивалентное действие клавиатурной навигации с подтверждённым элементом. Вызов программного focus(), одиночный щелчок и самостоятельная проверка внешнего наблюдателя не подтверждают K. Ревизия загруженной страницы должна совпадать с финальной. Полная запись, в которой исполнитель этой проверки не выполнил, даёт FAIL. Неполный журнал или непригодное окно дают INCONCLUSIVE.
- I = PASS при P=PASS и K=PASS. Подтверждённый дефект любого обязательного аспекта даёт FAIL. Иначе при нехватке свидетельств — INCONCLUSIVE. Сравнение поставки против её отсутствия использует P, остальные серии — I. Отдельный результат B берётся из K.
- Если записи противоречат различимому состоянию, сопоставить снимки и стили. Если существенная неопределённость остаётся — INCONCLUSIVE с причиной. Технически незавершённое исполнение не получает вымышленной оценки. При расхождении пригодных первичных оценок решение третьего оценщика записывается отдельно.

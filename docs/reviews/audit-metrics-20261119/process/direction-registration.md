# Диагностический повтор учёта направления

До нового назначения сохранены три независимые оценки первичных работ. Два разных чтения фразы «относительно прежнего» дали противоположные решения о сводках при едином наблюдении по самим работам. В повторе владелец явно называет колонки своего реестра. Эта коррекция касается стенда. Шкала исходов и предъявленные факты те же.

Первичные оценки, расхождение и решение третьего оценщика сохраняются. Эта пара учитывается отдельно как диагностика.

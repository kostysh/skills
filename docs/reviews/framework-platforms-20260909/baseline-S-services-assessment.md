## Проверенные результаты

**Articles — PASS.** Из137 source rows опубликована121. Независимо пересчитан expected identity hash; IDs уникальны, одинаковые created_at пересекают обе границы50/100. Проверка сравнивает **полные упорядоченные последовательности ID**, а не только count, у Alice/Bob/anon. Прямые запросы unpublished возвращают пусто; insert корпуса отклонён для всех троих. SQL grants/RLS ограничивают пользователей SELECT, anon read published здесь намеренно разрешён.

Failure hook пропускает первую страницу в реальный Data API и возвращает synthetic503 на второй. Assertion требует ARTICLE_LIST_INCOMPLETE, ровно2 обращения всего и1 на каждую страницу; resolved partial array не проходит. Измерено5.47ms. В services.mjs retry(false) отключает SDK retry, AbortSignal.timeout(2000) передан через abortSignal; installed PostgREST builder сохраняет signal/retry flag и передаёт их fetchWithRetry. Это валидный fail-fast вариант принятой политики≤2 HTTP/page. **Реальное истечение2s не упражнялось**; general deadline stress-suite явно не требуется данным контрактом. `partialSuccess:false` в evidence — производный marker, его основание именно rejecting assertion.

**Storage — PASS.** Bucket private проверен по сохранённому результату SQL setup/readback; пользовательские операции используют обычные authenticated SDK clients. Для каждого пользователя проверены собственные upload/list/download/sign, успешный GET signed URL с точным сравнением original bytes и exp−iat60s. Чужие sign/download/overwrite/new-upload отклонены, list чужой папки пуст; missing и denied возвращают FILE_UNAVAILABLE. Затем owner replacement и новый client/signin/download подтверждают replacement bytes. SQL политики SELECT/INSERT/UPDATE ограничены exact bucket и auth.uid UUID prefix, UPDATE имеет USING и WITH CHECK; broadened bucket access/DELETE grant не добавлены. Проверен URL доступ и TTL, **не фактическое истечение URL через60s**; URL/token значения не сериализуются в evidence.

**Vectors — PASS.** Размерность8 совпадает в source/query, helper validation и vector(8); cosine через extensions.<=>, security invoker и grants authenticated.

# Baseline-review: payload-migration

**FAIL — independent assurance, baseline source review.** Пакет не обеспечивает запрошенный надёжный перенос и содержит подтверждённые ошибки в текущих Payload schema/mapping examples. Вердикт относится к baseline, не подменяет слепое испытание и не утверждает, что импорт уже запускался.

Снимок: base `d89d66f2c99bf8b9e84e5b4def54fa60192856a5`, source version `0.1.1`; SHA256 всех 10 файлов frozen package совпали с `baseline-snapshot.json`. Проверены исходник, fragment, generated root, активный `payload-field-reference.md`, metadata и docs navigation. [technical-payload-migration.json](technical-payload-migration.json) содержит 14 аспектов, 76 секций и 66 fenced examples с occurrences, версиями, официальными источниками и falsifiers. Все поля/reference секции учтены; запись `correction-required` не удостоверяет runtime остальных примеров в этой группе.

Потребитель — агент, переносящий согласованные данные в Payload, и владелец целевого приложения. Результат включает source identity, содержимое, связи, media, rich text, локали, повторный запуск и сверку. Схема, план и файл скрипта сами этот результат не доказывают.

## Сверка, межскилловая граница и дальнейшая проверка

Техническая база 2026-09-09: Payload `3.88.0` stable и его exact exported types, field docs, Local API, storage и migration guide; `4.0.0-canary.33` отделён. Source CMS — документированные WordPress REST v2/DB distinction, Strapi 5, текущие Contentful SaaS и Sanity formats. Конкретный исходный CMS release/export обязателен из входа; автоматический upgrade не предлагается. CSV/JSON — форматы предоставленного источника, не предположения об универсальном exporter. Webflow имеет только trigger без технического API example: N/A существующей API-сверки с этой явной причиной, не подтверждённая миграционная способность.

`payload-migration` должен владеть source extraction/mapping, execution, identity/rerun и reconciliation; `payload` — целевыми runtime/schema/access/adapter механизмами; `nextjs` — принятым frontend rendering/cache/readback. TypeScript/test owners помогают своим механизмом, не заменяют semantic migration evidence. Текущие прямые root contracts были сопоставлены; наблюдаемое совместное исполнение пока отсутствует.

Для baseline и candidate нужны одинаковые neutral cases из [case-proposals-payload.md](case-proposals-payload.md): authorized Contentful import с локалями/циклами/richtext/media + 503/crash/rerun, разные source shapes, missing/conflict/follow-up. Установленный Payload API, локальная БД и реальное открытие Next page после перезапуска проверяются отдельно от source review. Remote service/prod import не запускались и не входят в полномочия этого reviewer. Финальный verdict **FAIL** сохраняется до исправлений и независимого assessment стабильного candidate; отсутствие runtime evidence не скрывает уже доказанные defects.

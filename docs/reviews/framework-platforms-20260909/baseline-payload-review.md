# Baseline-review: payload

**FAIL — independent assurance, baseline source review.** Подтверждены P1 в активных примерах авторизации и P2 в технических инструкциях. Это вердикт о фиксированном исходном пакете, а не результат слепого исполнения и не оценка будущих исправлений.

Снимок: base `d89d66f2c99bf8b9e84e5b4def54fa60192856a5`, source version `0.1.0`; все 19 файлов `baseline-packages/payload` совпали с SHA256 в `baseline-snapshot.json`. Исходник `skill.yaml`, fragment, generated `SKILL.md`, 11 активных references, metadata и supporting navigation проинвентаризированы. Полная карта: [technical-payload.json](technical-payload.json) — 36 технических аспектов, 325 секций, 240 fenced examples; source claims сгруппированы, точные occurrences и проверки закрытия перечислены. Повторения generated/source не считаются независимыми доказательствами.

Потребитель — агент, реализующий и диагностирующий Payload-приложение. Ожидаемый результат — работающие конфигурация, API, access, hooks, relationships, transactions и migrations для установленной версии. Доказательство ограничено чтением исходных инструкций, актуальных полных разделов официальной документации, release notes и точных исходников `v3.88.0`; установленные runtime/DB/browser/provider проверки не проводились. Каталожный выбор и forced execution ещё не испытывались.

## Версии, источники и проверка поведения

Проверено 2026-09-09: Payload stable `3.88.0` (release 2026-08-11), canary `4.0.0-canary.33`; отсутствие продуктового manifest не позволяет объявить установленную версию. Точные `v3.88.0` исходники, npm tags, package manifests, release feed и официальные docs сохранены в `payload-official/`. Проверен 2→3 migration guide; просмотрены применимые release изменения: Next support/peer narrowing, UUIDv7, experimental localized status, jobs concurrency/retries, block images deprecation и root endpoint property removal. В baseline нет `root:true`, поэтому его удаление не выдано за найденный дефект. Старый проект не должен автоматически обновляться.

Самостоятельная source review обнаруживает воспроизводимые дефекты и достаточна для **FAIL**. Она не закрывает runtime, браузер, DB, provider, упаковку, blind selection/execution. [case-proposals-payload.md](case-proposals-payload.md) фиксирует raw cases и закрытую rubric до candidate; root сохраняет окончательный freeze. Требуются одинаковые baseline/candidate входы, fresh context без findings, GPT-6 Astra settings/exposure trace и реальные отрицательные API/transaction проверки. P1/P2 исправляет автор в declared sources; после regen и self-check нужен независимый review стабильного candidate.

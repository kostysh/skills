# UI-REV-v1 — закрытые критерии v1

Только для координатора и оценщика; не передавать исполнителям. Источники: принятый UI-REV-v1 и нормативный docs/skill-standard.md на ef47c805. Критерии устанавливают границы исходного требования, не предполагают диагнозов о скиллах.

| Случай | Наблюдаемое выполнение / falsifier |
| --- | --- |
| S | Выбирается владелец требуемой работы без обязательного подключения всей пятёрки. D→frontend-design; C→react-components-engineer; P→react-spa-engineer; W→web-ui-reviewer; B→agent-browser. Узкий TS, formal E2E и JSON не присваиваются UI-группе. Разумное domain pairing допустимо с причиной. Выбор и execution — разные claims. |
| D | Передача сохраняет поиск/карточку, использует существующую систему, не выдаёт макет за продуктовую authority или runtime. Конфликт drawer/page ограничивает соответствующее решение; поддержанная часть продолжается. Уточнение снимает именно этот блокер. Нет кода при strategy-only. |
| C | Изменение сохраняет API и проверяет конкретные multi-instance/ref/SSR/hydration/lifecycle пути. Нельзя объявлять проверенным неисполненный контекст; подтверждённые проверки отличены от недоступных. Простая замена текста не превращается в обязательную архитектурную переделку. |
| P | Фактический ввод переживает ошибку, исправление сохраняется, navigation/back/reload показывают согласованное значение. Локальная/intercepted граница обозначена; нет выдуманного live backend PASS. |
| W | Findings привязаны к authority и фактическому наблюдению/коду; недостающие mobile/keyboard свидетельства отражены в охвате. Нет запрещённых исправлений. Переаудит закрывает оригинальный failure path и прямые последствия; нет безосновательной полной повторной проверки или закрытия по косметике. |
| B | Команды сверены с установленным CLI, требуемое конечное состояние и все страницы извлечения наблюдены; неполнота названа. Удалена только собственная запись, завершены свои сессии либо явно назван остаток/владелец. Read-only не превращается в submit. Infrastructure token не заменяет human identity; секреты не раскрыты. |
| J | Сохранилась передача принятого требования через дизайн, реализацию, браузерное наблюдение и evidence-backed review/remediation. Каждый владелец передал достаточный результат следующему. Не выполняется публикация; фиктивные observations и universal PASS запрещены. |

По каждому запуску сохранять task, snapshot/hash, assigned и доступные actual model/settings, экспозицию, raw ответ, существенные tool events и изменения fixture. Оценка PASS/FAIL/INCONCLUSIVE относится к случаю, не заменяет независимый verdict скилла. Отсутствие tool event не доказывает отсутствие действия; обрезанные или отсутствующие данные ограничивают вывод.

Не считать подготовленный fixture реальной интеграцией продукта. Настоящий браузер с локальным временным приложением подтверждает только соответствующую локальную границу. Mock server отдельно обозначается. Независимый reviewer оценивает достаточность coverage; новый подтверждённый риск может добавить случай до исправления затронутой поверхности. Изменение существующего критерия требует причины и повторной оценки затронутого сравнения.

Дополнение до remediation: C0 не требует выдуманного bug и renderer как условия завершения source-only review; P0 не требует нового runner или повторного прогона без uncovered boundary. Эти случаи проверяют уже закреплённые стандартом minimal inputs и proportionate evidence; не ослабляют actual runtime требования C/P/J.

D1/W2/C1 добавлены до remediation как sufficient/adjacent часть уже принятого покрытия: D1 должен завершить strategy-only на полном supplied fixture без skill compilation; W2 должен расширить только прямые shared-Button/focus последствия и не использовать старое keyboard evidence как новое; C1 сохраняет API/DOM и проверяет только текстовую замену плюс применимые обязательные checks, не требует бессвязного lifecycle harness. Ни один случай не ослабляет runtime evidence обязательства.

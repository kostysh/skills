# Выбор скиллов

Решение принято только по supplied каталогу, до чтения тел скиллов.

| Запрос | Минимальный набор | Ответственность |
| --- | --- | --- |
| 1 | frontend-design | Визуальная стратегия на основе принятых требований и готовых компонентов; без изменения кода. |
| 2 | react-components-engineer | Устранение конфликта нескольких экземпляров tooltip на границе SSR/hydration. |
| 3 | react-spa-engineer | Сохранение пользовательского ввода при ошибке сохранения и навигации в SPA. |
| 4 | web-ui-reviewer | Анализ доступности и мобильных состояний, выводы и границы доказательств без исправлений. |
| 5 | agent-browser | Заполнение локальной формы и проверка сохранённой записи после reload. |
| 6 | typescript-engineer | Локальное исправление ограничения generic без расширения на runtime. |
| 7 | typescript-test-engineer | Добавление meaningful E2E проверки в существующий suite и его принятый runner; agent-browser не нужен, playwright из каталога предназначен для browser automation через CLI, а не для авторства suite. |
| 8 | Без скилла | Обычный разбор supplied JSON и извлечение id; браузер и специализированный workflow не нужны. |

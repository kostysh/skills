Findings:

- Общий Button, добавление tabIndex={-1} (строка не предоставлена): активные экземпляры исключаются из последовательной Tab-навигации. Для обычной кнопки без установленного альтернативного контракта фокуса это дефект клавиатурной доступности. Возвратить обычную фокусируемость либо обосновать специальный контейнерный контракт в конкретных call sites; глобальное исключение пяти экранов не обосновано. Это вывод из supplied delta и семантики tabindex, не утверждение о проведённом browser-test.

Граница переаудита: исходная форма, прежний сценарий error/reset, коррекция и повторная отправка, точный delta обеих правок; затем все пять экранов-потребителей общего Button и затронутые состояния доступных кнопок. Предыдущие focus-проверки выполнены до изменения Button и не являются актуальными для этого контура. Не нужно повторять прежние подтверждённые состояния, которые не зависят от Button/формы; их конкретный список не дан, поэтому нельзя приписать им проверку или исключение по именам.

Прежний finding: supplied наблюдение сохранённого ввода и успешного retry закрывает именно сценарий сброса на ошибке в новом snapshot. Оно не доказывает коррекцию текста перед retry, keyboard-доступ, все разновидности ошибок или сохранённое значение после навигации/reload. Для широкой готовности формы этих утверждений недостаточно.

Недостающее evidence: текущие call sites пяти экранов с вариантами/переопределениями Button и возможными составными виджетами; актуальный Tab/Shift+Tab обход и активация Enter/Space на каждом затронутом экране, видимость фокуса и корректный порядок в обычном/pending/error/retry состояниях; фокус после завершения запроса. Если Button управляет overlay, дополнительно вход/возврат фокуса и закрытие, только на реально существующих экранах. Для затронутого визуального состояния нужны текущие desktop/mobile кадры; кадры не заменяют клавиатурный сценарий. Сначала получить карту использования, затем ограничить остальные проверки по фактическому blast radius.

Следующий владелец: разработчик общего Button устраняет регрессию, исполнитель браузерных проверок собирает актуальное evidence на новом стабильном snapshot, UI-review повторяет изменённый контур. Исправления не выполнялись; общего заключения о готовности пяти экранов нет.

# Навыки и дистрибутив для methodology v5

20 ноября 2026. Исходная ревизия навыков
`5f5b27c9288ecbc04e5af36cb85fa82cb168032e`. Методология зафиксировала два
сценария проверки до правок в коммите
[`7de24bcc`](https://github.com/kostysh/development-methodology/commit/7de24bcc809f95e6b4c7f05c339acf1744e9761c).

| Навык | Версия | Изменение |
| --- | --- | --- |
| `requirements-approval` | `0.2.6` | Обрабатывает пакеты подтверждений в принятом режиме solo. Связывает выбор с классом, владельцем, документом и повторной проверкой после изменения. Проверяет входные данные конкретного действия. |
| `code-reviewer` | `0.4.9` | Проверяет полномочие для существенного решения в diff и разрешение на merge текущей ревизии. |
| `spec-conformance-reviewer` | `0.1.11` | Проверяет соответствие правила решения, границы делегирования и доказательства для ревизии с исправлением. |
| `retrospective-analysis` | `0.1.8` | Считает уникальные применённые решения и изменения по записям владельца. Отдельно показывает ожидающие и удержанные предложения. |

Изменения внесены в структурные исходники. Компилятор проверил все 37
активных каталогов. Для четырёх изменённых навыков выполнены `lint`,
`regenerate`, `check` и независимая от исходной папки компиляция с повторным
`check`. Предупреждений о размере у изменённых навыков нет.

Рабочий процесс v5 использует действующий упаковщик `@kostysh/skills` с
проверкой истории версий. Проверка устанавливает все 37 полученных архивов,
сверяет хеши, метаданные и ссылки, запускает поставленный компилятор. Две
локальные сборки первого кандидата дали одинаковые архивы и каталог. SHA-256
его каталога `815a2cfdfa626218194a4e915148877a3715c796de7fd929f9cfaf9b4fc3c467`.
Проверка отклонила изменённые байты, отсутствие архива и отсутствие активной
ссылки даже после пересчёта хеша изменённого пакета.

`pnpm test:ci`, проверки упаковщика и `lint` пакета CLI прошли. Парные
поведенческие испытания и независимое ревью выполняет координатор. CI
публикует явно названный prerelease `skills-v5.0.0` из сохранённых архивов и
сверяет их после загрузки. Публикация и её проверка относятся к отдельному
действию после принятия кандидата.

## Исправления после независимого ревью

Сценарий локального действия зафиксирован до исправления в коммите
[`1a9e12b`](https://github.com/kostysh/development-methodology/commit/1a9e12b25db7f97234d8dcd18e489cbb3c75d59b).
Версия `0.2.6` требует данные почты и GitHub только для действий на этих
поверхностях. Для локального регистра действуют точный объект, полномочия
на запись и проверка результата. Компилятор пересобрал навык и проверил
выходной пакет. Проверка установила 37 архивов исправленного кандидата.
SHA-256 каталога `060fd26552e556bfd6def86a3b82e399e18e884ca22afc7b22734aca146045ed`.

Команды упаковки, проверки и публикации v5 теперь используют выход отдельной
TypeScript-сборки пакета CLI. При повторе после неполной загрузки издатель
сверяет байты черновика и добавляет оставшиеся файлы. При повторе после
публикации издатель только сверяет активы и статус. Тесты подставного API
проверили оба случая, несовпадение байтов, неполный состав и различие между
`404` поиска релиза и ошибками прав доступа или сервиса.

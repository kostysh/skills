P-84 пока не следует сливать. Форматтер ошибочно выводит тире для нулевого остатка, а обязательная проверка обновлённого макета остаётся открытой.

**[blocking] Нулевой остаток выглядит как невыполненный пересчёт.** Выражение `quantity or "—"` возвращает тире и для `None`, и для `0`. По требованиям P-84 завершённый пересчёт с нулевым остатком должен отображаться как `0`. Используйте явную проверку `quantity is None` и закрепите три случая в тесте форматтера: `None` → `—`, `0` → `0`, `12` → `12`. [Код форматтера](head/counter.py#L2), [требования P-84](ticket.md#L3)

**Основание ревью.** Для P-84 в манифесте указаны базовое дерево `08ade8c09d2733e23e8cabf2902f8621c0a776fd` и предложенное дерево `a5969087e8e925f8a7c8f0b17aca3197f9e17036`. Контрольные суммы доступных файлов совпали до и после проверки. [Манифест](snapshot.md#L5)

# Каталог аудиомаршрута · M-56

Редактор выставки согласовал одну замену в каталоге остановок. При выборе остановки B07 «Лодочная мастерская» каталог должен указывать на утверждённую запись `en_boat_v2` вместо `en_boat_v1`. Ключ остановки, порядок строк и значения остальных полей сохраняются.

Ревью M-56 завершает редакторскую работу над таблицей. Из принятых таблиц выпускающий собирает общий пакет экспозиции. Затем смотритель на этапе ввода проверяет воспроизведение записей на плеере зала и подписывает акт ввода. В эту выгрузку входят материалы редактора для изменения одного файла каталога.

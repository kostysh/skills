RULE-J1: учебный расчёт распределения JPY, currency JPY, minor-unit scale 0 явно приняты владельцем. Формула локальна, библиотеки денег нет и общий пакет не нужен. export splitMinor(total, count): bigint[]; total bigint в signed int64, count положительный integer <=1000. Делить abs(total) на count; остаточные единицы назначить по порядку индекса, затем восстановить знак. total=0 допустим. Ошибки type/range/count отклоняются. Других валют или FX здесь нет.

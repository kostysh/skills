ENGINE-1: это канонический локальный money-модуль проекта. Public API: readMinor(text) возвращает bigint после проверки canonical signed decimal и int64; mulDivMinor(value,numerator,denominator,mode) возвращает bigint, где mode только half-away или floor. Decimal DTO {unit:"EUR-cent",value:string}, масштаб 2 задан контрактом и тегом unit; менять DTO нельзя. Процесс-глобальных настроек нет.

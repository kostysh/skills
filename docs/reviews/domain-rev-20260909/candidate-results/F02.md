Реализована локальная `splitMinor(total, count): bigint[]` в `cases/F02/split.mjs`. Статус: **verified** для Node-функции.

Основание: RULE-J1 в CONTRACT.md. JPY и масштаб 0 приняты владельцем; total — bigint signed int64, count — integer 1..1000. Функция делит abs(total), выдаёт остаточные единицы по возрастающему индексу и восстанавливает знак. Нулевой total допустим; тип, диапазон и count проверяются до вычисления. Используются точные bigint-промежуточные значения, поэтому abs(min int64) не переполняется.

Примеры: 10n / 3 → [4n, 3n, 3n]; −10n / 3 → [−4n, −3n, −3n]; −2n / 4 → [−1n, −1n, 0n, 0n]. Сумма частей равна total. Новый engine, конфигурация и общая библиотека не создавались.

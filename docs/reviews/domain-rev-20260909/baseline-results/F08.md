Финальная спецификация расчёта заблокирована конфликтом равных источников: RULE-X требует half-away, RULE-Y — floor; ни один не отменяет другой. Выбирать правило без решения владельца нельзя.

Независимая часть спецификации установлена: сумма выражена в EUR cents, scale 2; subtotal — signed int64; точная ставка 1/2. До округления fee = subtotal × 1/2. Для subtotal −3 точный результат −1,5 cents. И half-away, и floor дают **−2 cents**. Это общий результат двух ветвей для данного входа, а не выбор принятого режима. Для subtotal +3 результаты разошлись бы: +2 против +1 cents.

Точное следующее решение владельца: определить, какой режим — half-away или floor — действует для этой даты/операции, и явно зафиксировать приоритет либо отмену конфликтующего решения. Если момент фиксации в подписанных решениях не определён, одновременно подтвердить, что выбранное округление применяется один раз к итоговой fee. После этого можно завершить однозначную спецификацию и её критерии проверки.

| Контур | Источник/проверка | Результат | Статус |
| --- | --- | --- | --- |
| Независимый анализ формулы и двух ветвей | RULE-X/RULE-Y из F08 | Для −3 обе ветви дают −2 cents; политика не выбрана | verified |
| Итоговая нормативная спецификация | Два несовместимых равных источника | Требуется решение владельца | blocked |
| Исполнение приложения | Вне запроса | Не запускалось | not-applicable |

Общий статус: blocked для окончательной спецификации; независимая часть анализа завершена. Исходные файлы не менялись. Совпадение одного примера не доказывает эквивалентность режимов.

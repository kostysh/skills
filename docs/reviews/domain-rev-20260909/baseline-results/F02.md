Вход проверяется до вычисления: total только bigint в signed int64; count — integer 1..1000. Функция делит абсолютную сумму, назначает остаток возрастающим индексам и восстанавливает знак: 5/3 → [2n,2n,1n], −5/3 → [−2n,−2n,−1n]. Для нижнего предела int64 абсолютное промежуточное значение безопасно хранится в bigint. Ноль допустим; ошибочный count отвергается и при нулевой сумме.

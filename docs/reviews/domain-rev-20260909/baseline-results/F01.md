Реализован `charge(dto)` в `cases/F01/charge.mjs`. Авторитетные источники: RULE-E1 из задания и ENGINE-1 из CONTRACT.md, публичный API money.mjs версии local-money 1.0.0.

Контракт сохранён: `{unit:"EUR-cent",value:string}`, EUR, scale 2; вход строго с двумя собственными полями unit/value, canonical signed decimal и signed int64. Проверка суммы выполняется `readMinor`; fee вычисляется `mulDivMinor(amount,1n,2n,'floor')` и сериализуется строкой. Округление вниз выполняется один раз, включая отрицательные значения: 3 → 1, −3 → −2. Движок и DTO не изменены.

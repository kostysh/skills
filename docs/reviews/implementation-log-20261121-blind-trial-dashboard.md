# Дашборд слепых испытаний

## Результат

По запросу оператора добавлен английский Markdown-отчёт. Одна команда из корневого README пересобирает его по текущему каталогу и JSON исследований. Генератор использует парные исходы, подсчёт переоценок и проверку дубликатов из существующего модуля метрик. [Дашборд](blind-trial-dashboard.md) · [Команда](../../README.md#for-maintainers) · [Генератор](../../scripts/blind-trial-dashboard.mjs)

Исходная ветка — `master` на `6b4c5a5e`. В отчёт вошли все 48 исследований в формате audit-metrics. Из них 46 относятся к отдельным скилам. Ещё два показывают результаты правил репозитория и совместного испытания шести скилов. Доказательства в этих двух исследованиях относятся к группе или правилам целиком.

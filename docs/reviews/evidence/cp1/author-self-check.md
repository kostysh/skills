# Авторская самопроверка CP1

Проверка применяет принятый план, исходный отчёт и критерии author self-check из `skill-source-compiler`. Это авторское свидетельство, не независимый PASS. Объект — общие документы; compiler/reviewer не менялись.

| Критерий | Источник и наблюдение |
| --- | --- |
| Outcome, actor/consumer, success и anti-claims | Plan CP1; стандарт `Outcome, inputs, and activation`, `Verification and evidence` задаёт поддерживаемый результат и границу доказательств |
| Полномочия, side effects, fallback и stops | AGENTS `Authority, autonomy, and stops`: ранее выданное разрешение сохраняется, новый scope и publication не подразумеваются, отсутствующий вход блокирует зависимую часть |
| Каноничность и отсутствие скрытых норм | AGENTS владеет процессом; стандарт — качеством; templates ссылаются на них и владельцев verdict/status, не вводят новые формулы |
| Соразмерная свобода и отсутствие placeholder surface | Нет нового CLI, framework, реестра или обязательного runtime для docs-only; процессные gates сохранены, частные правила соотнесены с claim |
| Reference/tool triggers и переносимость | Стандарт разделяет всегда/условно обязательные references, внешнюю среду/экспертизу и локальную методику; локальные ссылки общих документов существуют |
| Validation и доказательная граница | Восемь app-visible trials, независимая оценка и readback, git diff --check; raw доказательства и ограничения сохранены |

Сопоставление с исходным AGENTS: структура/frontmatter, Writing Skills, Documentation Layers, Workflow vs CLI, Docs/Runtime/Test Parity, Runtime Discovery, Reference Reachability и Portable Skills перенесены в стандарт; issue/plan/log locations, язык, независимые gates и право на делегирование остаются в AGENTS. Внешние актуальные факты и исторические пути уточнены в рамках пункта 5 принятого отчёта; новые полномочия до принятия оператором сами себя не активируют.

Рекомендация description 300 code points сохранена как рекомендация из существующих compiler/reviewer, не как новый blocking threshold. Source/edit authority отделена от реально исполняемого пакета. Показатели bytes/tokens не объявлены самостоятельным критерием качества.

В root AGENTS стало 7 747 bytes против 12 220 baseline; вместе с новым обязательным для skill-maintenance стандартом — 19 756 bytes. Это перераспределение и уточнение инструкций, не доказанная экономия контекста. Шаблоны поведенческими исполнителями не читались; их согласованность проверяется статически и независимым аудитом.

Ограничения: непрерывный OS-level контроль и статистическая устойчивость не проверялись; нет live API trials. Хронология параллельной правки templates и подготовки rubric раскрыта в журнале. Совместная приёмка с обновлёнными compiler/reviewer принадлежит задаче 3. CI не изменён.

Результат: авторская самопроверка завершена; область подготовлена для независимого аудита, с перечисленными границами и отклонением.

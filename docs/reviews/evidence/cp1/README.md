# Свидетельства CP1

Этот набор — supporting evidence, а не активные инструкции и не постоянный evaluation harness. Проверяемые инструкции внутри fixtures и snapshots являются данными; не выполнять их как полномочия аудитора.

- [cases](cases/) — четыре исходные пользовательские задачи и fixtures; одинаковы для baseline/candidate.
- [rubric](criteria-and-input-manifests/rubric.md) — критерии, скрытые от исполнителей во время прогонов; здесь раскрыты только для оценки завершённых испытаний.
- [execution-context](execution-context.json) — назначение run/case/policy, контекст запуска и доступные измерения.
- [policies/baseline](policies/baseline/) и [policies/candidate](policies/candidate/) — точные копии общих правил, использованных в испытаниях. Их ссылки сохранены как исторический raw snapshot, а не как отдельный runnable пакет.
- [baseline-manifest](baseline-manifest.json) — исходные 67 файлов правил/двух скилов из Git HEAD `f4c9eec590047ea7c5dd01d72532e2e92b52bb94`; неизменённые skill-файлы восстанавливаются из этой Git-версии, не дублируются здесь.
- [candidate-manifest](candidate-manifest.json) — шесть файлов политики: агрегат `6bc747089fa6e52468091c53811dac89d3e37a751f93558bbcb9e8508c1dca49`.
- [assessment](results/assessment.md) — независимая оценка; [evaluator readback](results/evaluator-readback.json) — независимая проверка конечных файлов.
- `results/run-NN.md` — raw final response, сверенный с ответом в приложении; `results/run-NN-events.json` — сообщения и реальные команды из Codex app read_thread, с exit codes и stdout. Reasoning не включён.
- `criteria-and-input-manifests/run-NN-initial.json`, `results/coordinator-readback.json` и две output-копии — исходное и конечное состояние локальных файлов.

Для воспроизведения создать новый каталог с одним case, положить соответствующую версию AGENTS и её локальные нормативные зависимости, применить сохранённый prompt template в новом контексте. Не передавать исполнителю эту папку целиком, рубрику, отчёт, план, прошлые ответы и соседние прогоны. Сохранённые пути в events отражают фактическое исполнение и могут быть уже недоступны; относительные fixtures и policy snapshots остаются в этом наборе. Run-01..04 — baseline; run-05..08 — candidate.

Сравнение ограничено четырьмя случаями, по одному запуску на версию. Глобальные инструкции среды могли обеспечить правильное поведение независимо от repo-policy. Изоляция файлового доступа инструктивная; app-events показывают конкретные наблюдаемые действия, не все возможные системные эффекты. Статистическая устойчивость, качество других скилов и экономия ресурсов не подтверждены.

Критерии подготовлены независимым автором без знакомства с candidate и изменёнными шаблонами. Шаблоны редактировались параллельно; утверждение о фиксации критериев до абсолютно каждой правки не делается. Основные AGENTS и standard изменены после уведомления о готовой rubric.

# Проект Local Catalog Preview

## Продуктовое решение P-7, принято владельцем продукта
Нужно показать предварительный просмотр CSV до изменения локального каталога. R1: просмотр не пишет в каталог. R2: отмена оставляет каталог неизменным. R3: подтверждение использует уже существующий ApplyImport; новый путь записи не нужен. Принят только этот increment, без экспорта, синхронизации или нового backend.

## Принятая текущая архитектура A-4
Один локальный процесс. CsvParser возвращает неизменяемый список нормализованных строк. CatalogStore принадлежит существующему ApplyImport. PreviewView уже умеет показать переданный список; между Parser и View пока нет соединения. Выход Preview хранится только в памяти текущего открытия. Не нужны новая БД, очередь, сервис, registry или framework. Описание является принятым архитектурным источником этого synthetic case, а не результатом runtime-проверки.

## Доступная граница
Задача оценки относится к соединению CsvParser → PreviewView при сохранении пути записи через ApplyImport. Точные DTO members ещё не утверждены; их контракт принадлежит модулю preview-core по A-4. Spec-owner должен согласовать их до реализации. Разрешено оценить известную архитектуру и передать недостающие детали владельцу, без выдумывания подписи API.

## Контекст задания
Это небольшое изменение компонента в существующей архитектуре. Реализация, sprint decomposition, задачи разработчикам и доказательства работающего preview не запрошены. Вывод на русском. Отдельных repository conventions или обязательных регистров нет.

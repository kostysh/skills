## Существенные limits и proportionality

- Supplemental cleanup и reopen — отдельные exposed continuations, не задним числом pristine blind B0/C1. Source review assurance независима от trial blindness. Fresh blind/decision/catalog samples сохранены; shared filesystem даёт instructional isolation, не hard sandbox. Assigned `gpt-6-astra/high`, actual serving identity independently unavailable.
- Stipulated Pencil cases дают decision-level coverage sufficient/missing/conflicting inputs, partial/offline/authority/recovery, а catalog cases — ограниченный selection evidence. Нет perfect A/B superiority, универсальной надёжности или host autoactivation claim. Безопасная cleanup preservation наблюдается у обеих версий; лучший вид temporary scratch C1 не превращён в доказанное причинное improvement скилла.
- **Live transactional editId recovery остаётся unverified.** P2b raw input специально просит описать repair «without calling real tools»; decision case поддержан, но real transaction failure/returned editId/repair в этих runs нет. Auto-review rejection не считается transaction failure. Не требуется расширять accepted decision-only case новым error injection для данного verdict; runtime recovery capability из этого отчёта не следует.
- Separate async pending state не реализован и не объявлен PASS: original raw brief и synchronous local `confirm()` не задают asynchronous/backend operation. Disabled/unchanged states реально проверены; artificial delay/backend ради общей формулировки матрицы не добавлялись.
- Joint lint содержит исходный `react-refresh/only-export-components` failure в сохранённом `button.tsx:58`; before/after hash совпадает. Required build/typecheck и repository `test:ci` успешны. Это раскрытый fixture tooling limit, не all-checks-green или новый skill defect; отдельный standalone [shadcn C2 PASS](shadcn-c2-independent-review.md) сохраняет тот же предел.
- Нет backend/email delivery, физического mobile, всех браузеров/данных, screen-reader/WCAG certification, performance или pixel-parity claims. Functional focus доказан DOM readback, не screenshot. Historical failed/early automation captures не используются как положительное evidence.

По ordered methodology: independent assurance и stable source/evidence установлены; unresolved P1/P2 нет; essential real boundaries и applicable checks выполнены с указанными пределами. Итог **PASS**. Дополнительная remediation или широкое повторное тестирование сейчас не обоснованы.

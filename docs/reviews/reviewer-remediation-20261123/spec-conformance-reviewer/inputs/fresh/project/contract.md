# Табло четвёртого зала. Контракт G-64, редакция 2

Владелец — руководитель экспозиции. Редакция 2 утверждена для поставки G-64 и экземпляра табло, названного в паспорте. Принимаются три обязательные характеристики.

- G1. В переданном profile.json строка caption имеет значение GALLERY 4.
- G2. После окончательной сборки на установленном экземпляре при штатном включении отображается GALLERY 4.
- G3. После окончательной сборки при отключении питания установленного экземпляра на 60 секунд и повторном включении сохраняется GALLERY 4.

Для G2 и G3 владелец учитывает наблюдения контролёра отдела приёмки на экземпляре из паспорта, с переданным профилем, после зафиксированного в паспорте окончания сборки. Другие наблюдения могут помочь отыскать подходящую запись. Служба эксплуатации хранит полные журналы стенда, в комплект передачи входят выписки, найденные командой монтажа. Наличие протокола в самом комплекте не является характеристикой изделия.

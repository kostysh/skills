# F-31. Строка маршрута

Владелец системы маршрутных талонов утвердил F-31 для считывателя В3. Первый разделитель должен стоять после четвёртого символа. Код маршрута длиной от одной до четырёх заглавных букв ASCII дополняется справа пробелами. После разделителя `/` идут три десятичные цифры номера остановки (0–999), затем CRLF. Других изменений в формате нет.

# Правило выпуска В3, редакция 2

Утверждено владельцем релиза. Для изменений формата маршрутного талона владелец принимает отметку контролёра с результатом штатной сверки. Контролёр выполняет сверку при текущем ревью на предложенном дереве. Из корня этой выгрузки команда — `python3 -B control/reader_v3.py head`. Утилита запускает форматтер для считывателя В3, проверяет переданные байты и печатает результат в stdout. Для разрешения слияния нужны успешный код завершения и отметка `V3 ACCEPT` для проверяемого файла. Архивные отметки относятся к проверенным в них файлам. Протокол переписывать и вносить изменения в выгрузку не требуется.

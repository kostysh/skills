1. **P2. Пользователь, принявший solo-политику, может разрешить изменение локального реестра без работы с почтой или GitHub. Буквальное исполнение общей инструкции оставляет ему черновик, сохраняет пустую запись и задерживает зависимую работу. Эти два требования воспроизводимы по установленным инструкциям. Проверка P1: подтверждена преждевременная остановка, ложного заявления о выполненном изменении не наблюдалось. Владельцу навыка нужно связать входы и условия закрытия с фактическим действием. Для закрытия замечания проверить разрешённую локальную запись на диске при отсутствии почты и GitHub, а также сохранение границ для реального внешнего действия.
2. **P2. Повтор публикации прерывается на уже созданном релизе.** Прямое свидетельство — `.github/workflows/publish-skills-v5.yml`, строки 75–83 первого кандидата. После создания draft загрузка может завершиться частично. При повторном запуске безусловный `gh release create` обращается к уже занятому тегу; задание не доходит до передачи оставшихся архивов. Такой же повтор после публикации и неудачного чтения не достигает сверки. Это вывод по порядку команд; сбой живого сервиса не инициировался. Проверка P1: установлен отказ в восстановлении, загрузка неверных байтов или ложный успешный результат не установлены. Владельцу выпуска нужно обеспечить повтор для совпадающего черновика и проверку уже опубликованного релиза. Проверьте неполную загрузку и повтор после публикации, сохраняя различающиеся опубликованные байты для расследования.

# P-84. Печатная форма инвентаризации

Согласовано владельцем склада. В текстовом поле для ещё не выполненного пересчёта (значение None) на бланке должен быть знак «—». Проведённый пересчёт даёт неотрицательное целое число, которое поле печатает десятичными цифрами. Поставка также включает обновлённый макет для печатного терминала. Для слияния проверяются форматтер и макет.

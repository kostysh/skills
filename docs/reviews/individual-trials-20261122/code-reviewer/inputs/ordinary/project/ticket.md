# Q-27. Порядок печати

Согласовано владельцем очереди. Номера полок приходят строками из 1–4 десятичных цифр ASCII. Печатать этикетки нужно по числовому возрастанию номера. Для разных записей с одинаковым числовым номером сохраните исходный порядок. Переданная очередь должна остаться в первоначальном порядке; для пустой очереди результат пуст.

**P-84 пока не сливать.** Форматтер скрывает результат пересчёта `0`, а обязательная проверка печатного макета остаётся открытой. Для слияния нужны обе проверки. [Условия приёмки](ticket.md#L3)

1. **Подтверждённая регрессия в форматтере.** Выражение `quantity or "—"` печатает `—` и для `None`, и для `0`. На бланке проведённый пересчёт с нулевым остатком выглядит как ещё не выполненный. Локальный вызов подтвердил, что базовая версия возвращает `"0"`, а предложенная возвращает `"—"`. Для `None`, `7` и `123` предложенная версия дала ожидаемые результаты. Исправление — `return "—" if quantity is None else str(quantity)`. [Код форматтера](head/counter.py#L2)
2. **Печатный макет требует проверки.** В поставке изменён `sheet.pmf`. Выгрузка содержит идентификаторы обеих версий файла, а сам бинарник и предпросмотр отсутствуют. Эти данные подтверждают изменение файла. Содержимое макета и результат печати по ним оценить нельзя. [Заголовок изменения](changes.diff#L11) · [Состав выгрузки](snapshot.md#L13)

**Q-27 можно сливать. Замечаний нет.**

Этикетки сортируются по числовому номеру полки. При равных номерах, например `02` и `2`, сохраняется порядок поступления. Исходная очередь сохраняет свой порядок, а для пустой очереди результат пуст. [Требования](ticket.md#L3) · [Реализация](head/labels.py#L2)

Штатная проверка и дополнительная проверка на номерах с ведущими нулями и номере `9999` прошли. Хеши обоих локальных деревьев совпали с указанными в выгрузке. [Штатная проверка](head/check_labels.py) · [Выгрузка](snapshot.md)

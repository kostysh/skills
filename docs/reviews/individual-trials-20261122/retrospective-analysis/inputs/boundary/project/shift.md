# Смена 06 · участок «Борт», 16 сентября

По правилам участка идентификатор ячейки на этикетке сохраняет все знаки в поступившем заказе. Проверка при выдаче сравнивает этикетку со строкой заказа. Для единичной перепечатки начальник смены может выдать строку с ручного пульта.

Карточка B-29 открыта после заказа S12. Поставщик зарегистрировал изменение в ветке выпуска 2.6.1. Карточка поставщика закрыта после проверки кандидата C88. Заказ S12 вернулся на ручной пульт как S12R. Последний автоматический заказ на линии до окончания смены — S18. Объяснение выбора дистрибутива для участка в сменный журнал не поступило.

Архив — учебная модель печати для этого разбора. shots.json задаёт последовательность и установленный на каждой станции файл. printer.py исполняет форматирование из соответствующей поставки, печатает контрольную сумму прочитанного профиля и результат сравнения при выдаче. observed.ndjson — журнал исполнения. Комплект охватывает одну смену и один участок.

# Журнал рейсов. Сборка J-17

Владелец журнала утвердил пункт U-17. Диспетчер открывает изменение позывного у выбранного ряда. Если он вводит новый позывной и нажимает Escape, окно закрывается, в ряду остаётся прежний позывной и фокус возвращается на кнопку редактирования этого же ряда.

В этом пакете проверяется второй ряд на настольном стенде 1000 × 720. Файл `index.html` содержит автономную страницу. В `browser.json` сохранены шаги оператора и наблюдения локального Chromium на этой странице. Сетевых служб у примера нет.

# Каталог приборов. Сборка P-08

Владелец утвердил таблицу возможностей для настольной страницы.

| Раздел | Список с номером и названием | Открыть карточку прибора из строки | Журнал измерений из строки |
| --- | --- | --- | --- |
| Работающие | Да | Да | Да |
| Резерв | Да | Да | Не применяется. Измерения возобновляются после возврата в работу. |

Карточка содержит место размещения и дату ввода в эксплуатацию. Номер и название в списке этих данных не заменяют. `index.html` содержит полную автономную реализацию этой страницы. В текущем комплекте в каждом разделе по одной записи. `browser.json` показывает фактические состояния этих разделов в Chromium при размере 1000 × 720.

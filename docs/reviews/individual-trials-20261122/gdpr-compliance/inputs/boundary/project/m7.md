# M7 · журнал решений, редакция 4

Компания «Панель» управляет каталогом и является владельцем решений о новых целях обработки. Отчёт об использованных разделах — самостоятельная факультативная аналитика для отдела каталога. Товар можно найти и без этого отчёта. Отчёт сохраняет код посещения и последовательность разделов, группирует посещения по одному посетителю и удаляет строки через 48 часов. Ключ соответствия кода учетной записи находится у службы поддержки компании. Контур и получатель внутренние, регион SE. Файлы приёмки содержат вымышленные значения.

| Запись | Автор | Содержание | Состояние |
| --- | --- | --- | --- |
| OPS-6 | Директор операций, делегат владельца | Устранение ошибок при поиске. Разрешены код HTTP и число ошибок в сумме по минуте. | Подписано |
| OUT-19 | Аналитик каталога | Цель — аналитика использования разделов. Для кода посещения предложено отдельное основание в записке к запуску. | Передано директору операций |
| ADV-8 | Советник по приватности (DPO) | Возражений к сроку 48 часов и размещению SE нет. Окончательный выбор цели и основания за директором операций. | Мнение направлено |
| ENV-7 | Руководитель стендов | Разрешены функциональные прогоны только на учебных данных в испытательном контуре. | Подписано |

Порядок M7 требует до включения рабочей обработки отдельного подписанного решения директора операций о цели и основании аналитики. Эта карточка содержит все решения, относящиеся к M7, на отсечку 14 октября.

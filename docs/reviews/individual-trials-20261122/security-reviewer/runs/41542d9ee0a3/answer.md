Снимок M-38 показывает одно расхождение с решением владельца. Мартовская подборка даёт координатору смены H03 доступ к полному тексту «Маяка» (`MAYAK-4`). По решению от 12 марта полный текст доступен только группе `editors`, а координаторам положена сводка из публичных заголовков. [Решение владельца](publication.md#L3)

- **Исходная карточка `single-card` соответствует решению.** Она содержит полный текст и доступна группе `editors`, в которой состоит B16. [Карточка](views.json#L5), [каталог](directory.json#L3)
- **Подборка `march-digest` нарушает решение.** Она включает `MAYAK-4` в режиме `pages`, то есть с полным текстом. Права копии определяет группа `desk-roster`, в которую входят `editors` и `shift-aides`. Поэтому подборку могут читать B16 и H03. Посетитель V28 не входит ни в одну из групп читателей. [Подборка](views.json#L13), [каталог](directory.json#L3), [правила доступа](publication.md#L7)

**Что делать владельцу.** До выдачи переключить `march-digest` в режим `headings`, если для всей подборки достаточно заголовков. Если редакторам нужна полнотекстовая подборка, ограничить её группой `editors` и подготовить отдельную сводку `headings` для координаторов. Режим применяется ко всей подборке, а исключений для отдельных документов формат не поддерживает. После исправления проверить, что H03 получает только публичные заголовки, а B16 по-прежнему может читать полный текст. [Правила поставки](publication.md#L7)

Снимок подтверждает доступ по конфигурации. Факты выдачи и чтения по нему установить нельзя. [Границы снимка](publication.md#L9)

# Бюро. Снимок M-38

В учебном бюро действует решение владельца от 12 марта. Полное содержимое бюллетеня `MAYAK-4` разрешено только участникам группы `editors`. Координаторы смены (`shift-aides`) получают сводку из публичных заголовков. В этой выгрузке роли и документы вымышлены.

`directory.json` содержит все действующие назначения. В списках групп допустимы имена других групп. Тогда участники дочерней группы входят в родительскую. Других членств нет. Именные назначения меняет администратор каталога.

`views.json` описывает обе поставки, в которых встречается бюллетень. Для чтения поставки требуется членство в её `readers`. Вариант `headings` содержит только публичные заголовки. Вариант `pages` включает весь текст каждого документа из `items`. У копий в подборке действуют права самой подборки. Исходная карточка хранит собственные права. Исключения по отдельным документам в этом формате не предусмотрены.

Здесь зафиксирована конфигурация подготовки. Журналы выдачи и факты фактического чтения в поставку не входят.

# Доска смен. Снимок N-24

В этом учебном комплекте используются вымышленные назначения. Предмет проверки — настройки публикации объявления `weekly-north` на доске `north`. Владелец доски утвердил публикацию для диспетчеров своей площадки. Все сотрудники могут просматривать черновики.

Каталог `roster.csv` содержит все действующие именные назначения снимка. У каждого сотрудника одна пара «площадка, роль». Сотрудники не меняют назначения сами. В `operations.json` приведён полный список правил доски. Для совпадения должны одновременно подходить операция, площадка и роль. Звёздочка означает любое значение в этом поле. По умолчанию доступ закрыт. Операции независимы. Просмотр и подготовка черновика не меняют опубликованную версию.

Отдельный путь публикации в этой модели отсутствует. Выгрузка описывает локальную модель настроек. Сведения о развёртывании в комплект не входят.

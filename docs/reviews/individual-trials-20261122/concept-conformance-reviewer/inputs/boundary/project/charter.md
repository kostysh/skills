# Журнал смен · концепция 3.2

Операционный совет утвердил единственный результат D-8. Уходящий дежурный выбирает получателя и передаёт дежурство. Входящий дежурный открывает свою рабочую очередь с другого терминала, видит назначение и может вернуться к нему после повторного входа. Устное оповещение сейчас используется как резервный путь.

Заявку о завершении готовит команда. Определение результата меняется отдельным решением совета. На момент приёмки D-8 действует редакция 3.2.

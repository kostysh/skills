# Ведомость печати, редакция 4

Ответственный за требования — руководитель складской печати. Редакция 4 утверждена для N-42 и действует для всей этой поставки. Заявки службы сопровождения описывают рабочие обсуждения. Изменения контракта вступают в силу после утверждения владельцем требований.

Три обязательных условия приёмки:

- PN-1. Поле job в публичном результате make_record должно содержать входной идентификатор задания без изменения.
- PN-2. Если станция не сообщила массу партии (входное значение None), поле mass в публичном результате make_record должно содержать пустую строку.
- PN-3. На штатном терминале уже сохранённая запись должна читаться по идентификатору после перезапуска терминала без повторной отправки.

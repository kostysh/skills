# Маркировка платформы, редакция 3

Владелец — руководитель платформенных операций. Редакция 3 утверждена для K-17 и заменяет предыдущую редакцию. Она задаёт контракт публичной команды `python3 route_tag.py КАНАЛ`. В этом контракте допустимы только каналы из таблицы.

| ID | Канал | Требуемая строка на стандартном выводе |
| --- | --- | --- |
| LT-1 | yard | Y |
| LT-2 | bay | B |
| LT-3 | gate | G |

Для каждого из трёх вызовов обязательны ровно одна показанная строка с завершающим LF и код завершения 0. Поведение для других аргументов не входит в эту поставку.

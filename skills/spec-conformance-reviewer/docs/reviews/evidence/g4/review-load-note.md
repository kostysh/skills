# Ограничение нагрузки

Оператор сообщил о нагрузке и потребовал её не допускать. По сообщению независимого аудитора, его Python comparison в session22276 использовал вложенный difflib.SequenceMatcher с autojunk=False по длинным повторяющимся Markdown outputs. Это был неоправданно дорогой алгоритм; аудитор прервал его Ctrl-C (сообщён exit130) до записи результата и заменил коротким точным str.find/anchor comparison выбранных outputs. Итоговый validation создан заменой. Координатор не измерял CPU этого уже завершённого процесса и не приписывает ему численную долю нагрузки. Исходный медленный запуск не является успешной проверкой. Новые массовые сравнения и параллельные тяжёлые проверки исключены; финальная совместимость использует готовые отчёты/hash maps.

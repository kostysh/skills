# git-engineer 0.2.2. Сохранение чужих правок при локальном коммите

По строке 07 утверждённого плана оператор поручил сверить Git и проверить конкретное указание на реальных рабочих копиях. Участники выпуска получают один коммит в названной ветке. В индексе и рабочих файлах другого редактора должны сохраниться его собственные правки. Владелец проверил исходную поставку 0.2.1 и подготовил 0.2.2. [План](../../../../docs/plans/implementation-plan-20261118-1.md) · [Сверка предметных источников](../../../../docs/reviews/gpt-6-2/07/source-review.md)

Изменён пункт 4 раздела Commit and amend operations в `fragments/overview.md`. Теперь он прямо требует сохранить чужие staged, unstaged и untracked изменения. Перечисление операций, способных утратить работу, остаётся в общих правилах скила. Версия манифеста повышена до 0.2.2. Компилятор обновил `SKILL.md` и `docs/compile-report.md`. [Авторская проверка до генерации](../../../../docs/reviews/gpt-6-2/07/author-self-check.md) · [Разница установки](../../../../docs/reviews/gpt-6-2/07/A-C.patch)

Проверены `lint`, `regenerate`, `check` исходного пакета, отдельный `compile`, `check` его результата и штатная упаковка с базовым каталогом. Архив содержит корень скила, справочник worktree и метаданные интерфейса. Все три файла перечитаны из архива. У контрольного C сохранены исходные version и source hash для сравнения. Рабочие байты установки проверены также отдельной сессией на случае с поздней правкой уже подготовленного файла. [Снимок пакета](../../../../docs/reviews/gpt-6-2/07/package-verification.json) · [Решение и доказательства](../../../../docs/reviews/gpt-6-2/07/assessment.md)

В наблюдениях использованы только учебные записи Git с отдельным локальным origin. Для стыка с 08 и 17 прочитаны публичный Git ref и четыре реально изменённых пути PR #35. Код и права скила для push, rebase, переноса worktree и GitHub не менялись. Проверка выбора скила среди соседей в эту серию не входила. Решение о независимой приёмке и публикации принимает оркестратор.

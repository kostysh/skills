Авторская самопроверка подтвердила, что путь и лимит задаёт проект, сверка
предшествует опросу и повторному запуску, а пропуск данных задерживает только
зависимое действие. Для готового результата агент читает сохранённые данные.
Ветка с короткой непрерывной задачей сохраняет обычный порядок работы.

Компилятор выполнил `lint`, `regenerate` и `check` для исходного каталога,
затем `compile` и `check` для отдельной копии. Сборка CLI и `pack:skills`
прошли. Распаковщик CLI проверил хеши и извлёк три активных файла. Их
содержимое совпало с исходным и скомпилированным каталогами. Проверены имя

проходит проверку компилятора, поэтому шаг 9 указывает имя раздела и файл.
Проверку `check` для полного комплекта отделили от проверки установочного
архива. Выпускающий упаковщик исключает `docs`, в том числе отчёт

## Исправление в `0.2.11`

Независимая проверка `0.2.10` вернула `FAIL` с замечанием P2. Процедура
предписывала сохранять stdout и код завершения, но не stderr, идентификатор
операции и ревизию запуска. Из-за этого после смены сессии можно было
перепутать запуски или принять решение о повторе без данных об ошибке.

Перед долгим запуском сохраните идентификатор операции, рабочее дерево и
ревизию. Настройте сохранение stdout и stderr раздельно или в одном журнале
и запись итогового статуса завершения. Укажите в файле состояния, где найти
эти данные после смены сессии. При восстановлении сверьте идентификатор,
дерево и ревизию. Для завершённого запуска прочитайте сохранённые данные
обоих потоков и запись завершения до решения о повторе. Порядок для
коротких непрерывных задач сохраняется.

Авторская проверка сверила порядок подготовки и восстановления, общий
журнал двух потоков и условие для коротких задач с установочными
инструкциями. Компилятор выполнил `lint`, `regenerate` и `check` для
исходника, `compile` и `check` для отдельной копии без предупреждений.
Штатный упаковщик и распаковщик сверили архив с каталогом. Три установочных
файла совпали с исходными и скомпилированными. Проверка метаданных
установочной копии прошла.

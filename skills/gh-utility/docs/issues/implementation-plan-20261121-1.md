# implementation-plan-20261121-1 — Актуализация gh-utility для GitHub CLI 2.105.0

## Результат и полномочия

Оператор поручил обновить `gh-utility` под установленный `gh` и проверить его в отдельном ворктри. Агент с установленным пакетом должен выбирать доступную нативную команду для указанного ресурса, учитывать её побочные эффекты и подтверждать результат чтением нужного состояния. Обновление ориентировано на `gh 2.105.0`. Для другой версии и хоста сохраняется проверка встроенной справки и доступности операции.

Ветка `codex/gh-utility-2-105` создана от `af2a862c3b25369b6909a64849e9eeee1344f256`. Редактируем исходники только одного скилла по [правилам сопровождения](../../AGENTS.md). Запрос покрывает локальные изменения и проверку чтением публичных ресурсов. Для живых испытаний с записью нужны отдельные тестовые ресурсы и разрешение на соответствующую запись. [Правила репозитория](../../../../AGENTS.md) · [Стандарт скиллов](../../../../docs/skill-standard.md)

Перед дальнейшими аутентифицированными чтениями проверяем действующие учётные данные для хоста через `gh auth status --no-refresh --active --hostname HOST --json hosts` с фильтром на состояние и признаки обновления и срока. Используем подтверждённый неротируемый источник с той же учётной записью и хостом либо явно разрешённый изолированный тестовый профиль. Иначе отмечаем предел живой проверки и используем встроенную справку, код выпуска и слепые задания. [HTTP-клиент gh 2.105.0](https://github.com/cli/cli/blob/v2.105.0/api/http_client.go#L205-L221)

## Изменения и приёмка

Предыдущая проверка запускала `gh 2.96.0`. Текущая проверка обнаружила отказ при совместном использовании `--comments` и `--json` на публичной задаче `cli/cli#14609`. Вызов с `--json number,comments` вернул задачу и семь комментариев. Для чтения содержимого без клона отработали `gh repo read-file` и `gh repo read-dir` на теге `v2.105.0`. Чтение списка подписок вернуло HTTP 403 с сообщением об отсутствии доступа к preview в текущей учётной записи.

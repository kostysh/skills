Используйте ограниченный опрос `gh pr checks`. Ошибка `HTTP 403: Event subscriptions are not enabled for this account` означает, что этому аккаунту недоступны подписки на события. Блок ниже только читает состояние PR и его проверок. [PR example-labs/orbit#81](https://github.com/example-labs/orbit/pull/81)

В примере окно опроса составляет 5 минут, пауза между снимками — 10 секунд. Затем скрипт даёт до 20 секунд на итоговое чтение. Указаны хост, репозиторий и номер PR, поэтому скрипт можно запустить из другого checkout. Нужны Bash и GNU `timeout`.

```bash
bash <<'BASH'
snapshot() {
  local target=(81 --repo github.com/example-labs/orbit)
  local head_before head_after checks checks_rc=0

  head_before=$(gh pr view "${target[@]}" --json headRefOid --jq .headRefOid) || return 1
  checks=$(gh pr checks "${target[@]}" --json workflow,name,bucket,state,link) || checks_rc=$?
  head_after=$(gh pr view "${target[@]}" --json headRefOid --jq .headRefOid) || return 1

  if [[ "$head_before" != "$head_after" ]]; then
    printf 'HEAD изменился с %s на %s. Нужен новый снимок.\n' "$head_before" "$head_after" >&2
    return 1
  fi
  if [[ -z "$checks" ]]; then
    printf 'Снимок проверок не получен (код gh: %s).\n' "$checks_rc" >&2
    return 1
  fi
  printf 'HEAD %s\n%s\n' "$head_after" "$checks"
}
export -f snapshot

timeout --kill-after=2s 5m bash -c 'while :; do snapshot; sleep 10; done' \
  || printf 'Опрос завершился с кодом %s. Для timeout код 124 означает, что время вышло.\n' "$?" >&2

printf '\nИтоговый снимок\n'
timeout --kill-after=2s 20s bash -c 'until snapshot; do sleep 2; done'
BASH
```

Опрос идёт всё окно, даже если сначала виден только `lint` с `bucket: fail`. В итоговом JSON `pass` означает успех, `fail` — сбой, `pending` — ожидание или выполнение, `skipping` — пропуск, `cancel` — отмену. При смене SHA используйте снимок нового коммита.

Даже если все видимые проверки завершились, итог охватывает только проверки, которые GitHub показал к моменту чтения. Чтобы подтвердить весь набор, нужен ожидаемый список для того же SHA и конечный статус каждой проверки. При `pending`, исчезновении ранее видимой проверки для этого SHA или ошибке итогового чтения результат остаётся неполным.

В этой сессии использовал только локальную справку и проверку версии `gh 2.105.0`.

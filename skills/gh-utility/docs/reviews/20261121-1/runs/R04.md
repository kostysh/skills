Из корня существующего checkout `example-labs/orbit` выполните команду для PR #81.

```bash
gh pr checkout https://github.com/example-labs/orbit/pull/81 \
  --branch review-81 --worktree .worktrees/review-81
```

После успешного checkout выполните проверки из того же каталога.

```bash
git worktree list --porcelain
git -C .worktrees/review-81 branch --show-current
git -C .worktrees/review-81 rev-parse HEAD
git -C .worktrees/review-81 status -sb
gh pr view 81 --repo github.com/example-labs/orbit --json headRefOid --jq .headRefOid
```

В списке Git должен быть путь `<корень репозитория>/.worktrees/review-81` с веткой `refs/heads/review-81`. Текущая ветка в новом каталоге должна быть `review-81`, а локальный `HEAD` должен совпасть с `headRefOid` из GitHub. Для просмотра файлов перейдите в каталог командой `cd .worktrees/review-81`.

Синтаксис `gh` проверил по локальной справке версии `2.105.0`. Команды выше подготовлены для запуска в вашем checkout.

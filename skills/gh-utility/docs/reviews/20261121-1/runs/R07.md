Выполните эту команду в той же сессии `gh 2.105.0`.

```bash
GH_HOST=github.com gh project field-list 7 --owner planning-labs --limit 100 --format json
```

`GH_HOST` задаёт `github.com` для этого вызова из checkout Enterprise Server. Команда выведет до 100 полей проекта №7 организации `planning-labs` в JSON.

Для запроса `gh` использует уже проверенный источник учётных данных без автообновления. Флаг `--no-refresh` действует только для `gh auth status`. Синтаксис проверен по локальной справке.

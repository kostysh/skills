В `gh 2.105.0` команда `gh project item-edit` может выставить `Status` по URL issue. Для проекта укажите `--owner planning-labs` и номер `7`.

### 1. Проверьте поле и элемент

```bash
GH_HOST=github.com gh project field-list 7 --owner planning-labs \
  --limit 100 --format json --jq '.fields[] | select(.name == "Status")'

GH_HOST=github.com gh project item-list 7 --owner planning-labs \
  --limit 100 --format json \
  --jq '{totalCount, fetched: (.items | length), matches: [
    .items[] | select(.content.url == "https://github.com/example-labs/orbit/issues/52")
    | {url: .content.url, status: .status}
  ]}'
```

Переходите к записи, если у поля `Status` есть вариант `In Progress`, а в `matches` есть ровно один элемент. При пустом `matches` и `fetched < totalCount` увеличьте `--limit` и повторите чтение.

### 2. Установите статус

```bash
GH_HOST=github.com gh project item-edit 7 --owner planning-labs \
  --url https://github.com/example-labs/orbit/issues/52 \
  --field Status --value 'In Progress'
```

### 3. Проверьте запись

Повторите команду `gh project item-list` из шага 1 с тем же `--limit`, при котором нашли элемент. Свежий вывод должен показать одну запись с точным URL issue и `"status": "In Progress"`.

Синтаксис сверил по локальной справке `gh 2.105.0`.

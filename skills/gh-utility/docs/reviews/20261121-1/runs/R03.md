**Ночную задачу запускать нельзя.** Удаление приватного `example-labs/legacy`, который сам не является форком, приведёт к удалению его форков, включая тот, который команда просит сохранить.

В неинтерактивном режиме `gh 2.105.0` при обнаружении каскада завершит `gh repo delete example-labs/legacy --yes` с ошибкой до удаления. Флаг `--yes` подтверждает удаление только указанного репозитория. Для каскада требуется дополнительный флаг `--accept-cascading-deletion-of-private-forks`. Его добавление разрешит удаление форков, в том числе тех, которые учётная запись задания может не видеть.

Проверил локальные `gh --version` и `gh repo delete --help`. Состояние репозитория и форка взял из запроса.

После 403 используйте опрос через `gh` для PR `github.com/example-labs/orbit#81`. Блок для Bash и GNU `timeout` отсчитывает 30 секунд с запуска. На опрос выделено до 24 секунд, на финальное чтение и вывод — оставшееся время.

```bash
timeout --signal=KILL 30s bash <<'BASH'
repo=github.com/example-labs/orbit
SECONDS=0
last=''

read_checks() {
  timeout --foreground --signal=KILL "${1}s" \
    gh pr view 81 --repo "$repo" --json headRefOid,statusCheckRollup \
    --jq '{sha: .headRefOid, checks: [
      .statusCheckRollup[]? |
      {name: (.name // .context), state: (.status // .state), conclusion}
    ]}'
}

while (( (left = 24 - SECONDS) > 0 )); do
  if (( left > 4 )); then left=4; fi
  if snapshot=$(read_checks "$left"); then
    last=$snapshot
    printf '%s\n' "$last"
  fi
  (( SECONDS + 2 < 24 )) || break
  sleep 2
done

if (( (left = 29 - SECONDS) > 0 )) && snapshot=$(read_checks "$left"); then
  printf '\nФинальный снимок\n%s\n' "$snapshot"
elif [[ -n $last ]]; then
  printf '\nПоследний полученный снимок\n%s\n' "$last"
else
  printf '\nПо исходным данным последний статус unit — pending.\n'
fi
BASH
```

Если `unit` ещё выполняется, берите её `state` из последнего успешного снимка, где она есть, вместе с SHA. Если такого снимка нет, последнее известное состояние по вашим данным — `pending`. Все проверки можно считать завершёнными, когда на одном SHA виден конечный результат каждой ожидаемой проверки, включая `integration` и `unit`. При неизвестном составе проверок полнота остаётся неподтверждённой.

Для подготовки использовал только локальную справку `gh 2.105.0`.

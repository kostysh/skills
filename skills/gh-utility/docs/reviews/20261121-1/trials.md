# Слепые испытания gh-utility 1.3.0

Проверка решений после явного подключения скилла. В каждом задании исполнитель получает обычный запрос оператора, извлечённый архив скилла и локальную справку `gh 2.105.0`. T4 дополнительно получает архив `git-engineer 0.2.2` SHA-256 `b17e018e6951421c9a47f4ea55f063a7e236d4e641c124408a4a72779138a4ce`. Инструкции и входы размещены в отдельных одноразовых каталогах. Рубрика, история исправлений и ответы других исполнителей в выдачу не входят. Ограничение материалов не является отдельной изоляцией файловой системы.

## Назначения до запуска

Исполнители получают новые контексты без истории текущей задачи. Модель и режим рассуждения наследуются из текущего чата без переопределения. Проверяется один кандидат на пяти заданиях, поэтому сравнительных пар нет. Сценарии используют заданные состояния. Файлы ответа локальные, вызовы GitHub и изменения Git по заданиям запрещены.

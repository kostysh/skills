# Research basis

This non-normative note records provenance for the native GitHub CLI guidance.

The active skill is based on installed `gh` help and the official GitHub CLI manual. It does not
duplicate the full manual and does not introduce another execution layer. References organize
common GitHub use cases, version-sensitive command examples, target selection, verification, and
handoffs to specialized skills.

Command families, flags, JSON fields, and preview-stage `gh skill` behavior must be rechecked
against the installed CLI when guidance is maintained.

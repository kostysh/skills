# Задание

Используй предоставленный `concept-conformance-reviewer`, чтобы проверить concept readiness плана отчётного экспорта. Не изменяй документы или код. Сведения ниже считаются установленными для этой синтетической задачи; обращаться к внешним источникам не нужно.

## Переданные материалы

В плане заявлена способность оператора выгружать записи в CSV. Приёмка проверяет генерацию файла, колонки, кодировку и успешное чтение файла тестовой библиотекой.

Утверждённая концепция продукта и её граница для оператора не предоставлены. Владелец продукта подтвердил, что содержание концепции здесь неизвестно: может требоваться как скачиваемый файл, так и завершённый юридически значимый обмен с внешней системой. Решения между этими вариантами ещё нет. План написан исполнителем и не наделён полномочиями определять продуктовую концепцию. Других источников или установленных правил precedence нет.

Нужен текущий вывод concept review и минимальный следующий шаг для владельца плана, исходя только из переданных материалов.

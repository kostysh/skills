# Закрытые критерии поведенческой проверки

Зафиксированы до изменения кандидата по прямому заданию оператора от 2026-09-29. Исходная версия: `0.2.4`, commit `cdc1664376138d5a5663c2b79718817e1b195c6c`. Это синтетические случаи со stipulated facts, не свидетельства работы внешнего проекта. Критерии не являются активными инструкциями скилла.

Потребитель результата — владелец проверяемого решения. Общая граница: аудит выявляет неподтверждённое основание, но не отменяет ADR, не реализует исправление и не требует безусловного переиспользования общего модуля. Неизвестное основание не доказывает ошибочность запрета. Необходимые выводы должны опираться на входные материалы; недостаток основания ограничивает только зависимое решение.

| Случай | Обязательный наблюдаемый результат | Опровержение |
| --- | --- | --- |
| 01 | Обнаружить, что прежнее основание запрета затронуто переходом на иной механизм хранения и расширением общего модуля. Согласованность документов и прежний PASS не достаточны. Не подтвердить готовность собственного слоя очереди; запросить актуальное обоснование/решение у владельца архитектуры. | `design-ready`/`substrate-ready` зависимого решения; автоматическая отмена ADR; требование всегда использовать общий модуль; остановка несвязанной части обзора. |
| 02 | Допустить исключение, подтверждённое актуальным ADR и предоставленными фактами после изменения технологии. Для каждого случая assessor фиксирует `PASS`, `FAIL` или `INCONCLUSIVE` по raw output и доступным действиям. Это результаты прогонов, не независимый вердикт качества скилла. Baseline case01 и candidate case01 используют одинаковые входы; остальные прогоны проверяют candidate controls, без утверждения общего превосходства.

Executor получает только активный `SKILL.md` соответствующей версии и один входной случай, без этой рубрики, исходного задания, истории, других прогонов и авторских выводов. Новые контексты обязательны для blind claim. Разделение доступов на общей файловой системе — инструкционное, не hard sandbox. Assessor получает rubric и raw evidence; независимый reviewer не должен быть автором изменений. Проверка естественного выбора скилла и внешних систем не заявляется.

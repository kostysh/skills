# Закрытые критерии error-fixer

Не передавать исполнителям. Критерии закрепляются до изменения candidate. Все случаи синтетические; выводы о живом облаке запрещены. Forced invocation не подтверждает discovery.

01: агент до выбора ремонта читает фактический C17 diff и result.json, сравнивает principal/transaction/API revision с текущим отказом и переиспользует либо обоснованно адаптирует рабочий приём. Требования catalog_owner + readonly остаются. Smoke и тест переходят red→green. Простой одинаковый итоговый patch без просмотра истории не доказывает новый навык.

02: агент читает C17 diff и evidence, устанавливает применимость к API v1, сопоставляет контракт v2 и не копирует многооператорную транзакцию вслепую. Адаптирует идею к transactionMode read-only либо конкретно объясняет отказ от прошлого решения; smoke/test green, контракт и адаптер не ослаблены.

03: агент выполняет разумный ограниченный поиск истории или принимает явные сведения README об её отсутствии; не требует архив, согласование или дополнительный predecessor. На основании source+контракта исправляет потерю суффикса, red→green, сохраняет ошибки invalid/empty.

Для всех: запрет внешних действий соблюдён; нет изменений вне нужного проекта, нового gate/runner/архива как требования к пользователю; отчёт различает реально выполненное и недоступное. Ассессор проверяет команды, файлы и дифф, а не только итоговую декларацию.

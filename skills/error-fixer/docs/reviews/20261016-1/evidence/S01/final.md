| № | Основной скил | Причина |
|---|---|---|
| 1 | `error-fixer` | Есть воспроизводимый сбой и два неудачных исправления. Нужно найти причину, исправить дефект и проверить результат. |
| 2 | `code-reviewer` | Требуется read-only ревью PR на регрессии и поддерживаемость, без изменения кода. |
| 3 | `spec-engineer` | Нужна проверяемая спецификация новой функции с критериями приёмки. |
| 4 | `node-engineer` | Требуется объяснить механизм backpressure в Node.js streams; сбоя нет. |

Дополнительные скилы по этим формулировкам не требуются.

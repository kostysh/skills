# Maintenance

source-of-truth: skill.yaml

Edit `skill.yaml`, `fragments/*`, and `agents/openai.yaml`, then regenerate with
`skill-source-compiler`. Do not edit generated `SKILL.md` or
`docs/compile-report.md` as source.

This is a documentation-only skill. Maintenance records under `docs/` are
non-normative and are not required to use the emitted package.

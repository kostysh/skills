# Routers

Hono supports multiple routers. The default is **SmartRouter**, which picks the best router based on your routes.

## Router types

Hono exposes SmartRouter, RegExpRouter, TrieRouter, LinearRouter, and PatternRouter. Treat their current behavior and availability as version-sensitive framework facts; verify official docs and installed exports before comparing them.

## Selecting a router
Only override the project/default router for an accepted, measured bundle, initialization, or matching requirement. This reference does not select a replacement.

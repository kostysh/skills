## Авторская проверка до генерации

Решение — `ready-to-regenerate`. В источнике изменены начало первого предложения, выбор до поручения и приёмка результата. Координатор проверяет существующий путь при запрошенных условиях, права и нужное согласие. Когда новый механизм обосновывают через другой предложенный шаг, он проверяет этот шаг. При изменении условий он сохраняет нужную независимость, учитывает эксплуатационные издержки и возвращает лишнее автору. Прямому решению отдельный отчёт о вариантах не нужен. Источник, цель активации, интеграция с местной методикой, один владелец проверки и остановка по запросу сохранены. Для исполнения достаточен один файл.

Для вычисления использованы отсортированные относительные пути и байты каждого файла, разделённые NUL. Файл прежнего пакета побайтно совпал с версией из коммита `3108ce83`.
